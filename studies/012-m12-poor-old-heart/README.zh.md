# M12 贫而老的核心：Gaia XP 金属丰度与银河系最老的恒星

> English: [README.md](README.md)（M12 Poor old heart: Gaia XP metallicities of the oldest Milky Way stars）。以英文 `README.md` 为准（预注册与判据的权威文本）；本文件是它的中文译本，节号与表格一一对应，英文改动时在同一个 PR 中同步修改。网页在线版：[https://sudoghut.github.io/astrolab/studies/012-m12-poor-old-heart/web/](https://sudoghut.github.io/astrolab/studies/012-m12-poor-old-heart/web/)。

## 1. 问题

Rix 等 2022（ApJ 941, 45；arXiv:2209.02722；下称"R22"）用以 APOGEE DR17 训练的 XGBoost 模型，从 Gaia DR3 XP 光谱估计了银心 30° 以内约 200 万颗亮巨星的 [M/H]。他们报告约 18,000 颗 −2.7 < [M/H] < −1.5 的星、球对称高斯尺度 σ_RGC ≈ 2.7 kpc、至少约 5×10⁷ M☉ 的恒星质量、[M/H] = −2 以下没有净转动而 −1 附近以转动为主，并把这个族群解读为银河系最古老的原银河系成分。

只用 R22 的两个公开文件（Zenodo 记录 7035810），我们问：

1. R22 的计数能否用公开样本复现，样本支持论文中不一致数字里的哪一个？（T1）
2. 空间尺度能否复现，在包含样本自身选择的似然、扁平或幂律形状以及"大多数星在 5 kpc 以内"的说法下是否成立？（T2a、T2b）
3. 转动—金属丰度关系能否复现：−2 以下没有净转动、−1 附近以转动为主，过渡有多急剧？（T3）
4. 这些结果在多大程度上依赖金属丰度标尺与误差？（T4）
5. 贫金属星中有多少是途经的 GSE 星或晕星，大多数的远心距是否小于 5 kpc？（T5）
6. 质量如何依赖换算选择？（T6，不作判定）

这些检验来自 Wiki 文章第三部分（[Study-012](https://github.com/sudoghut/astrolab/wiki/Study-012-poor-old-heart#中文)），那里把每项检验对应到 Lean 拆解（`argument/Argument.lean`）中的一个前提或缺口。年龄排序（"比盘更老"，`gap_onezone`）与原银河系解读（`gap_proto`）无法用这些文件检验，作为探索（第 4.9 节）。

本节与第 2–4 节写于 2026-11-21，在下载或打开任何数据文件之前。我们与数据的唯一接触是 Zenodo 页面：文件名、大小、MD5 校验和、许可证与一段说明（"1.5 million stars"，含 XGBoost T_eff、log g 与 [M/H]；"1.2 million stars"，含银心坐标、作用量与基本轨道参数）。那里没有说明列的布局；列在载入时读取（第 3 节），每项检验都按 R22 描述的量来定义。

## 2. 假设与判据

被检验的假设是 R22 对贫金属族群的描述：一方面是公开样本应当复现的数字（T1、T2a、T3），另一方面是应当经得起我们检查的性质（T2a 版本（ii）、T2b、T4、T5）。

**约定。**
- 自助法（bootstrap）区间是对恒星重采样得到的中心 95% 百分位区间。
- 由 N 次模拟计算 p 值、其中 k 次至少与数据一样极端时，p_boot = (1 + k)/(1 + N)。下面的设计用模拟通过次数与偏差中位数，而不是 p 值；通过次数连同其二项标准误 √(n·p(1 − p)) 一起报告，100 次中 80 次时约为 4。
- 每项检验有自己的标签。无法评估的检验标为"无法判定"并写明原因（例如"文件中没有该数据""方法偏差""未建模的选择""拟合在边界上"）。
- 标签按书写顺序检查；第一个适用的即为标签。

**总体解读。** 两个解读，都由标签机械地得出。
- **复现。** 以下任一成立时为**"未复现"**：T1 的摘要未复现；T2a 的复现标签为未复现；T3（a）为有净转动或净反向转动；T3（b）为不以转动为主（与 R22 说法的明确矛盾不算"部分"）。T1 的摘要复现、T2a 的复现标签为复现、T3（a）为没有净转动且 T3（b）为以转动为主时，为**"R22 的数字可由公开样本复现"**。其他（某个 T3 标签无法判定，或 T2a 的复现标签因缺少数据而无法判定）为**"部分复现"**，并列出各项检验。
- **R22 图景的稳健性。** T2a 的族群 σ 与 2.7 kpc 相符、T2b 的 5 kpc 比例确认、T4 稳健、T5 的 g 为少量或中等且 a₅ 确认时，为**"在我们的检查下成立"**。T2a 的 σ 不同、T2b 的 5 kpc 比例不确认、T4 敏感、T5 的 g 为大量或 a₅ 不确认时，为**"受到挑战"**（写明是哪一项）。其他为**"无法判定"**，列出无法判定的检验。

T2b 的形状标签、T3（c）与 T6 单独报告，不进入解读。

**什么会改变我们对方法的看法。**
- 如果载入检查表明金属丰度文件不是 R22 的样本（总数低于 100 万，或重复的 `source_id` 达到 1% 或以上），运行停止，解读由带日期的修订确定。
- 如果某项已知答案检查失败，它所保护的标签按表中规定为无法判定；报告偏差，方法只能通过带日期的修订和新的运行来改变。
- 如果文件中没有视差或测光，除非用户同意服务器端补充（第 3 节），T2 与 T6 中依赖视差的部分为无法判定。

**例外与预算机制。** 两个文件超过 50 MB 的单次下载上限，合起来也超过 200 MB 的研究预算。用户于 2026-11-21 同意只下载一次、保存在项目之外的系统缓存中，并就这两个文件超出研究预算（记录在 `TODO.md` 的 T-021、`log.md` 的 2026-11-21 以及计划 [`design/028-plan_*`](https://github.com/sudoghut/astrolab/blob/main/design/028-plan_m12-poor-old-heart-paper-study.md) 中）。
- 单个文件的上限用 `cap_consent`（T-038）放开，写明这一同意。
- 研究预算需要核心库的一项新能力，在实现阶段经双闸审查加入：一个以同意为条件、针对指定文件的预算例外，仿照 `cap_consent`。它只把指定文件的字节从一次运行的预算中扣除（不提高预算），把同意写入来源记录，不改动 `astrolab/config.py` 中的任何上限。`--refresh` 以及带刷新的探索不得重新下载这两个文件。如果缓存清掉了某个文件，再次下载需要再次征得用户同意。这一机制通过审查之前，运行不能开始。
- 指定文件的例外扣除两个文件的字节后，可选的 TAP 补充放得进通常的预算。它是一次额外的取数，只在用户同意时进行，并且必须在 2026-11-25 之前或 Gaia DR4 发布日之后进行（Gaia 档案已宣布 2026-11-25 到 12-02 停机）。

**载入检查**（在任何检验之前；每项结果写入 `results/load.json`）。
- **L1 校验和。** 两个 MD5 都必须相符。*失败：*停止。
- **L2 列。** 按名称把列对应到 `source_id`、[M/H]、T_eff、log g（金属丰度文件），以及 `source_id`、J_R、J_φ、J_z、偏心率、R_apo 与（如有）位置和速度（运动学文件）；记录对应关系。另外记录是否有 `l, b`、视差及其误差、G 与 BP − RP。*失败：*没有 `source_id` 或 [M/H] 时停止；同一个量有多个候选列时停止，以带日期的修订确定对应关系；没有作用量、偏心率或 R_apo 时，T3 与 T5 为无法判定（文件中没有该数据）；没有视差或测光时，见可选的 TAP 一行。
- **L3 行数与重复。** 记录每个文件的总行数。*失败：*重复的 `source_id` 达到 1% 或以上时停止（第 2 节）；低于 1% 时，去掉重复 `source_id` 的所有副本并记录数目。
- **L4 连接。** 记录运动学行中 `source_id` 能在金属丰度文件中找到的比例；低于 99% 时，连接只用匹配上的行，并写明比例。
- **L5 单位与符号。** 运动学文件中 [M/H] > −0.5 的星，J_φ 的中位数必须为正，R_apo 的中位数在 2 到 15（kpc）之间。*失败：*J_φ 的中位数为负时翻转 J_φ 的符号并记录；恰好为零时停止并修订；R_apo 超出范围时，从文件表头确定其单位，并在任何检验之前以带日期的修订记录。
- **L6 R22 的查询与文件之间的截断。** 在有相应列时，把 ϖ（0.01 mas 的箱）、ϖ/σ_ϖ（0.1）、BP 星等与 BP − RP（0.05 mag）、l 与 b（0.5°）的直方图与 R22 的查询（视差 < 1 mas、|b| < 30°、|l| < 30°、BP < 15.5、1.0 < BP − RP < 3.5、光度截断）比较。在 R22 查询允许的范围内，如果直方图在 c 处从每箱至少 50 颗星降到 0，就判定在 c 处有对量 X 的截断。对 ϖ/σ_ϖ，如果 ϖ/σ_ϖ < 1 的星少于 0.01%，也判定有截断；这条规则不给出 c 值，只导致"无法判定（未建模的选择）"，或导致把该截断加进似然的修订。第 4.3 节的似然中没有的、判定存在的依赖视差的截断（对 ϖ 或 ϖ/σ_ϖ）使 T2a 版本（ii）为"无法判定（未建模的选择）"，除非在任何拟合之前以带日期的修订把它加进似然。判定存在的对其他量（l、b、BP、BP − RP）的更严截断在模拟中施加。
- **L7 金属丰度范围。** 记录 [M/H] 的最小值、最大值与第 0.1 百分位，以及 −2.5 以下的星数。

## 4. 方法

### 4.1 坐标与样本

- 银心坐标系：R0 = 8.2 kpc，太阳在盘面上（z☉ = 0）；x 指向银心。这些是我们的选择（R22 没有说明式 1 用的值）。
- 视差零点：模型用 ϖ_corr = ϖ + 0.02 mas；截断作用于原始 ϖ。
- T2 的贫金属样本：金属丰度文件中所有 [M/H] < −1.5 的星。
- T3 与 T5 的运动学样本：与金属丰度文件连接的运动学文件中的星，按原样使用（不另加截断）。
- 随机种子固定并保存在结果中。

### 4.2 T1

对金属丰度文件直接计数。标签见第 2 节。区间已在上面固定；泊松噪声（√N，在 18,000 处约 1%）报告但不使用。

### 4.3 T2a

- **沿视线的密度。** 对位于 (l_i, b_i) 的星 i，真视差 ϖ（mas）对应距离 d = 1/ϖ（kpc）与银心距 R(ϖ)。n_i(ϖ) ∝ ϖ⁻⁴ ρ(x, y, z)，此处 ρ = exp(−R²/(2σ²))。似然以每颗星的方向为条件；覆盖区只通过哪些星进入样本起作用（在 T2b 中还通过 f₅ 的积分）。
- **网格。** 300 个节点，在 0.2 到 30 kpc 的距离上按对数均匀分布。检查：节点加倍时数据上的 σ̂ 变化必须小于 0.01 kpc；否则继续加倍直到满足。
- **版本（i），按 R22 所写。** L_i = ∫ n_i(ϖ) N(ϖ_corr,i; ϖ, σ_ϖ,i) dϖ / ∫ n_i(ϖ) dϖ，两者都对 1–30 kpc 的真距离积分。R22 的式 1 需要一个范围但没有给出；我们的范围现在固定：把查询中的视差 < 1 mas 当作真距离的范围（1 kpc），30 kpc 作为外限，银心周围几 kpc 的高斯在此之外没有贡献。
- **版本（ii），对观测视差的选择。** 原始视差上的 cut_i = min(1 mas, 100·10^(0.2(0.9 − (G_i − 1.5(BP − RP_i − 1))))) mas，原始视差服从 N(ϖ − 0.02, σ_ϖ,i)：L_i = ∫ n_i(ϖ) N(ϖ_corr,i; ϖ, σ_ϖ,i) dϖ / ∫ n_i(ϖ) Φ((cut_i − ϖ + 0.02)/σ_ϖ,i) dϖ，对 0.2–30 kpc 积分。选择项的推导：ϖ 是真视差（经零点改正）；原始视差 ϖ_raw = ϖ_corr − 0.02 ~ N(ϖ − 0.02, σ_ϖ,i)，所以原始视差通过截断的概率为 P(ϖ_raw < cut_i) = Φ((cut_i − (ϖ − 0.02))/σ_ϖ,i) = Φ((cut_i − ϖ + 0.02)/σ_ϖ,i)。这就是这里"截断作用于原始 ϖ"的含义。BP < 15.5 的极限与光度截断通过光度函数引入的距离依赖不在这一似然中；由模拟测量其影响。
- **拟合。** 在 0.5–10 kpc 上对 σ 做有界一维最小化（Brent 法）。数据拟合离边界不到 0.05 kpc 即为"在边界上"：此时版本（i）为未复现，版本（ii）为无法判定（拟合在边界上）。自助与模拟拟合在边界上时保留边界值。
- **区间。** 对恒星做 200 次自助重采样（下限）。
- **参考拟合。** −1.5 < [M/H] < −1 与 −1 < [M/H] < −0.5 的版本（i）与（ii），只报告：只做点拟合（不做自助或模拟），某个箱的星多于 50,000 颗时用固定的随机子样本（种子 12012，写入结果）。
- **已知答案模拟**（100 次，下限），在拟合数据之前生成：
  - *位置。* 从模型（以银心为中心、σ = 2.7 kpc 的球对称高斯）中抽取三维位置，限于查询的视场（|l| < 30°、|b| < 30°）与 0.5–30 kpc 的真距离；似然对 0.2–30 kpc 积分，包含这一范围。
  - *光度函数。* 光度函数样本为金属丰度文件中 ϖ/σ_ϖ > 10 且 [M/H] < −1 的星（这样的星少于 500 颗时用所有金属丰度）。对每颗光度函数星取 M′ = G − 1.5(BP − RP − 1) + 5 log10(ϖ_corr/100) 与其观测 BP − RP；其颜色用下面的消光模型在它自己的 (b, d) 处消红化。每颗模拟星抽取一颗光度函数星：其 M′ 与内禀颜色。我们假设光度函数不随距离变化。局限：光度函数样本已经通过了 M′ < 0.9，所以缺少从稍暗处散射进来的星，偏差可能被低估。
  - *消光。* A_G = a·exp(−|b|/b_d)·min(d, 8 kpc)/8 kpc，A_BP 与 E(BP − RP) 取自 Gaia DR3 的消光系数（实现时确定，在任何拟合之前以带日期的修订记录）。(a, b_d) 在固定网格上选取（a 从 0 到 5 mag、步长 0.05；b_d 从 1° 到 20°、步长 0.5°）：在每个网格点模拟一次（光度函数用同一组 (a, b_d) 消红化），把观测 BP − RP 的中位数与第 90 百分位，在 |b| 的 0–5°、5–10°、10–20°、20–30° 箱中与数据的贫金属星比较（2 个参数对应 8 个统计量）；保留差值平方和最小的网格点，相同时取最小的 a，再取最小的 b_d。
  - *观测量。* G 与 BP 由 M′、颜色与模拟距离处的消光得到；视差误差在 G 的 0.25 mag 箱内从数据的 σ_ϖ 中重采样；然后把每个截断（视差 < 1 mas、光度截断、BP < 15.5、1.0 < BP − RP < 3.5，以及 L6 判定的任何更严截断）作用于模拟的观测量。
  - *规模。* 持续抽取模拟星，直到截断后的星数等于数据中 [M/H] < −1.5 的星数。
  两个版本都拟合每次模拟；偏差为 median(σ̂) − 2.7 kpc，附对模拟做自助法得到的标准误。
- 如果没有视差或测光（L2）且未补充取数，T2a 与 T2b 为"无法判定（文件中没有该数据）"。

### 4.4 T2b

- **似然。** 第 4.3 节版本（ii）的似然，以每颗星的方向为条件，用于银纬 |b| ≥ 5° 的星（变体 3° 与 8°，只报告）；ρ 换成各个模型。
- **模型。** 球对称高斯（σ）；扁平高斯 exp(−(x² + y² + z²/q²)/(2σ²))，q 在 0.2–1.5；带扁率的有核幂律 (r_q² + r_c²)^(−α/2)，r_q² = x² + y² + z²/q²，r_c 在 0.05–3 kpc，α 在 1–8，q 在 0.2–1.5（引用 Kurbatov 等 2024 的单分量斜率 3.4 与"曙光"斜率 4.5 作比较）。
- **拟合。** Nelder–Mead，从 5 个起点（球形的 σ̂ 加 q = 1，以及在参数范围内的 4 次抽取）出发，取最好的。ΔBIC = 2ΔlnL − Δk·ln N，有利于更复杂的模型，N 为 |b| ≥ 5° 的星数，Δk = 1。
- **q 的剖面区间。** q 在 0.2–1.5 上以 0.05 为步长取网格（27 个点），每点重拟合 σ。q̂ 处的值为 Nelder–Mead 扁平拟合（在该处拟合 σ）；剖面由网格值加上这一节点组成，lnL_max 取该拟合与最佳网格值中较大者。95% 区间为 2Δ = 2[lnL_max − lnL_profile(q)] ≤ 3.84 的范围；端点由相邻节点之间 2Δ 的线性插值得到。如果 2Δ 穿过 3.84 超过两次，区间为 [最低穿越点, 最高穿越点]，包括其中 2Δ 高于 3.84 的内部区域，并加标记报告。如果在 q = 0.2 或 q = 1.5 处 2[lnL_max − lnL_profile] 仍低于 3.84，区间的该端即为网格边缘。检查：lnL_profile(1.0) 必须等于球形拟合的 lnL（误差 0.01 以内）。用于数据上第 1 步的标签以及每次模拟。
- **自助法。** 对 |b| ≥ 5° 的星做 200 次重采样，每次重拟合全部三个模型（各 5 个起点）；由此得到所选模型的 f₅ 区间，以及在旁报告的 q 自助区间。
- **模拟**（各 100 次，下限），按第 4.3 节生成并截取 |b| ≥ 5°：
  - 假阳性：q = 1、σ = 2.7 kpc，完备性 c(b, d) = 1 − 0.5·exp(−(|b| − 5°)/5°)·min(d, 8 kpc)/8 kpc 作为随机稀疏化。c(b, d) 有意不放进拟合的似然。这项检查的范围是对这一指定完备性（向盘面并随距离下降）的稳健性，而不是对每一种可能的未建模选择。如果数据的 σ̂（T2a 版本（ii））与 2.7 kpc 相差超过 0.2 kpc，就在 σ̂ 处再生成一组 100 次假阳性模拟，检查必须在两组中都通过；
  - 功效：q = 0.5、σ = 2.7 kpc；
  - 第 2 步（只在进行到第 2 步时，在对数据做完第 1 步之后）：最佳扁平高斯；每次第 2 步模拟都评估第 2 步的标签，不论其第 1 步的结果如何。
  假阳性或功效检查失败时，跳过第 2 步及其模拟，并报告为未运行。
- **5 kpc 比例。** f₅ = 模型中离银心 r < 5 kpc 以内的恒星比例（三维，所有方向；幂律在 18 kpc 以内归一化）。
- **对照族群。** |b| ≥ 5° 的 −1 < [M/H] < −0.5 巨星，用同样三个模型（各 5 个起点）与 q 剖面拟合，只做点拟合（不做自助或模拟），星数多于 50,000 时用固定的随机子样本（种子 12012）；只报告。

### 4.5 T3

- **量。** J_φ/J_tot，J_tot = √(J_R² + J_φ² + J_z²)，取自文件的作用量（符号按 L5 确定）。文件给出位置与速度时也报告平均 v_φ，并用 R0 = 8.0 与 8.4 kpc 重算；作用量本身不重算。
- **样本。** 主样本：3 < R_apo < 7 kpc。变体：不限 R_apo（有自己的标签，报告）。
- **统计量。** （a）[M/H] < −2 的平均值；（b）−1.1 < [M/H] < −0.9 的平均值；（c）以 −2.0、−1.8、…、−0.6 为中心的 0.2 dex 分箱平均值（8 个箱），拟合 f = a + (b − a)/(1 + exp(−([M/H] − m)/s))，s 在 0.01–2 dex，按各箱方差加权的最小二乘；方差来自第一轮 1000 次自助重采样，之后固定。宽度 = 2 ln 9 · |s|。s 在边界上或不收敛的拟合算作不收敛：在数据上，T3（c）为"无法判定（拟合失败）"；在自助重采样中保留边界值，并报告这样的重采样数。标签所用的区间来自第二轮 1000 次自助重采样（下限），每次重拟合（c）。
- **已知答案 w₀。** 100 次模拟：每颗星保留其 [M/H] 作为真值，−1.0 以下 J_φ/J_tot = 0、以上为 0.8，再加上与数据在该箱内标准差相同的高斯散布（8 个箱之外的星用最近箱的值）；观测 [M/H] 为真值加 N(0, e)，e 在文件给出时为该星的误差（主值），否则为 0.1 dex（无误差时的主值），以及 0.15、0.2 dex（变体）；模拟按与数据完全相同的方式分箱与拟合；w₀ = 100 次模拟宽度的中位数（0.1 dex 时预计约 0.30 dex）。

### 4.6 T4

- 变体：（i）[M/H] + 0.1 与 − 0.1；（ii）[M/H] 加 N(0, 0.1) 与 N(0, 0.2)，各 10 次噪声实现；（iii）在每个 0.25 dex [M/H] 箱内，去掉 T_eff 或 log g 在第 1–99（另一变体第 5–95）百分位之外的星。
- 在每个变体中（变体（ii）中的每次实现）：T1 计数（弹性）；两个版本的 T2a σ，作为变体 [M/H] < −1.5 样本上的点估计（不做新的模拟或自助法）；主样本的 T3（a）与（b）标签（新的 1000 次自助重采样）；按 R22 的选择得到的 T6 质量。变体（ii）中，σ 与质量取 10 次实现的中位数，T3 标签在至少 6 次中与基线不同才算改变。
- 弹性：每平移 0.1 dex 的 Δln N；只来自斜率的预测为截断处的 ln 10 × (d log10 N/d[M/H])，由观测累积分布在 ±0.2 dex 内求得。

### 4.7 T5

在 [M/H] < −1.5 的已连接运动学星（变体 −1.9 < [M/H] < −1.2 与 [M/H] < −1.2）上计算比例 g 与 a₅，1000 次自助重采样（下限）。RVS、ϖ/σ_ϖ ≥ 5 与 δv_RVS < 5 km/s 的选择偏向银心近侧，因而使 R_apo 有偏；与结果一起写明。报告去掉 g 中的星对 T1 计数与 T6 质量的影响，把 RVS 子样本的比例推广到整个尾巴（一个假设）。

### 4.8 T6

- N：T1 的 N(< −1.5)，以及 N × (1 − g)，g 取自 T5。
- m_giant：800 M☉（R22），1,000 与 2,000 M☉（我们对 M4 数字的解读）。
- f_bright：[M/H] < −1.5、ϖ_corr/σ_ϖ > 5 的星中，经颜色改正的 M_G = G − 1.5(BP − RP − 1) + 5 log10(ϖ_corr/100) 小于 0.5 者的比例（ϖ/σ_ϖ 截断使之偏向较近的星；写明）；没有视差或测光时，f_bright = 1 并标为"未计算"。
- f：1 与 2.5。
- 输出：每种组合下 M 的表格，以及 R22 的选择（N(< −1.5)、800、f_bright = 1、2.5）是否给出至少 5×10⁷ M☉。

### 4.9 探索（不作判定）

README 第 8 节的入口，用 `python -m astrolab explore` 运行，不属于正式运行：按 [M/H] 箱（−2.5 到 −2、−2 到 −1.5、−1.5 到 −1）拟合的 σ；对 [M/H] = −2 以下计数拟合的指数斜率，与 Chen 等 2025 的 k ≈ 0.6–2.0 比较（只有约 0.5 dex 与其范围重叠）；J_φ/J_tot 对 [M/H] 与老盘区域的对照（"比盘更老"在这里无法检验）；按 T5 轨道类别分开的贫金属星，比较尺度与转动（原银河系解读在这里无法检验）。

### 4.10 计算量与顺序

- **顺序。** 下载（一次，在预算例外下）→ L1–L7 → 消光网格 → T2a 的已知答案模拟、T2b 的假阳性与功效模拟（使用数据的方向、星等、颜色与误差，但不对数据的视差拟合任何模型）以及 T3 的 w₀ 模拟 → T1 → T2a → 对数据做 T2b 第 1 步 → T2b 第 2 步的模拟（只在进行到第 2 步时）→ T2b 第 2 步 → T3 → T5 → T6 → T4。
- **计算量。** 对约 20,000 颗星 × 300 个节点的一次似然求值约 0.1 s；一维拟合约 25 次求值，二参数拟合约 150 次，三参数拟合约 300 次（每个起点）。
  - 消光网格：101 × 39 ≈ 3,900 次模拟（不求似然），约 1 小时。
  - T2a：2 个版本 ×（1 + 200 次自助 + 100 次模拟）次一维拟合，约 30 分钟。
  - T2b 自助：200 × (25 + 5 × 150 + 5 × 300) ≈ 455,000 次求值，约 12.5 小时。
  - T2b 模拟：每次模拟做球形拟合、扁平拟合（5 个起点）与 q 剖面（27 × 25）；200 次模拟约 300,000 次求值，约 8.5 小时；第 2 步的模拟（如进行到）再加幂律拟合，100 × (5 × 150 + 5 × 300) ≈ 225,000 次求值，约 6 小时。
  - T3（两轮自助、100–300 次 w₀ 模拟）、T1、T5、T6：几分钟。T4：约 8 个变体（变体（ii）含 10 次实现）×（2 次一维拟合 + T3），约 1 小时。
  - 参考拟合与对照族群（在至多 50,000 颗星上的点拟合，每次求值约 0.25 s）：2 个箱 × 2 个版本 × 25，加 3 个模型 × 5 个起点与 q 剖面，约 3,000 次求值，约 15 分钟。
  - 第二组假阳性模拟（只在数据的 σ̂ 与 2.7 kpc 相差超过 0.2 kpc 时）：100 × (25 + 5 × 150 + 27 × 25) ≈ 145,000 次求值，约 4 小时。

- **安排。** 正式运行要等到没有其他研究在运行时进行。
- **结果**（`results/`）：`load.json`、`t1.json`、`t2.json`、`t3.json`、`t4.json`、`t5.json`、`t6.json`、`summary.json`，每个小于 1 MB（分箱或汇总；没有逐星表格）。

### 4.12 任何拟合之前的修订（2026-11-21）

以下实现选择于 2026-11-21 编写 `run.py` 及其辅助模块时确定，当时尚未下载或读取任何数据文件（也未做任何拟合）。第 1–4.11 节不变；它们没有说定的细节在此确定。（本小节取代原来的占位小节"4.12 运行前的修订：暂无"。）

1. **L2 列名。** 列名先化为只含小写字母与数字（"[M/H]" → "mh"，"phot_g_mean_mag" → "photgmeanmag"），再与 `data012.py` 中固定的候选列表（`MH_CANDIDATES`、`KIN_CANDIDATES`）比较；例如 [M/H]：mh、mhxgboost、mhxgb、xgbmh、xgboostmh、mhpred、mhxp、metallicity、feh；J_φ：jphi、lz、actphi、actionphi、jphikpckms；R_apo：rapo、apo、apocenter、apocentre、rmax。一个量匹配到多列，或者没有 `source_id` 或 [M/H]，运行停止（第 3 节 L2）。T_eff 与 log g 只用于 T4 的变体（iii），缺少时该变体为"未计算"。
2. **位置。** 若金属丰度文件没有 l、b 而有 ra、dec，用 astropy 由 ICRS 换算为银道坐标（Galactic）。l 取 (−180°, 180°]。
3. **L6 的判定。** 直方图覆盖 R22 允许范围内有星的区间，箱边取箱宽的整数倍。若某一侧最外的有星箱至少有 50 颗星，且其外直到允许范围端点的所有箱都为空，就在该处判定一个截断 c（有星区间内部的空箱是空洞，不是截断；R22 自己的界限是范围端点，不是截断）。L6 使用金属丰度文件的全部星与原始视差。每个带数值的已判定截断（包括依赖视差的）都作用于模拟（第 4.3 节"L6 判定的任何更严截断"）。
4. **T2 样本与网格。** l、b、ϖ、σ_ϖ、G 或 BP − RP 不是有限值，或 σ_ϖ ≤ 0 的星不进入 T2 似然，并计数（`t2.json: sample.n_dropped_nonfinite`）。金属丰度箱为 lo ≤ [M/H] < hi。积分为对数间隔节点上、以视差为变量的梯形求和；版本（i）有自己的 300 个节点，在 1–30 kpc 上按对数间隔，版本（ii）的 300 个节点在 0.2–30 kpc 上。节点加倍检查对两个版本都做，到 1,200 个节点为止（内存：20,000 颗星时每个似然约 0.4 GB）；到那时仍未收敛，则 `t2.json: grid_check.passed` 为 false。收敛情况按版本记录（`grid_check.converged`）：版本（i）未收敛时，T2a 的复现标签为"无法判定（网格未收敛）"；版本（ii）未收敛时，T2a 的总体 σ、T2b 的形状与 f₅ 以及 T4 的 σ 条件为该标签（此时 T4 即为该标签，除非其他条件使它为"敏感"）。无论哪种情况，两个解读都带 `pending_amendment` 标记（原因代码 `grid_not_converged_i` / `_ii`），等待带日期的修订。模拟在数据拟合之前以 300 个节点拟合（第 4.10 节的顺序）；若检查采用更多节点，每个模拟按其种子重新生成，并以采用的节点数重新拟合。每颗星的视差高斯以其最大节点为基准存储（对数另存），因此视差的离群值在单精度矩阵中不会下溢。
5. **光度函数。** 光度函数样本的 ϖ/σ_ϖ > 10 用原始视差（第 4.1 节：截断作用于原始 ϖ）。每颗光度函数星的 M′ 用它自己 (b, d = 1/ϖ_corr) 处的消光模型换成内禀 M_G0 = M′ + 1.5(BP − RP − 1) − A_G、内禀颜色 BP − RP − E(BP − RP) 与内禀 BP − G。距离为 d 的模拟星取 G = M_G0 + μ(d) + A_G、BP − RP = 颜色₀ + E(BP − RP)、BP = G + (BP − G)₀ + (A_BP − A_G)。这需要文件中有 BP 星等（模拟要施加 BP < 15.5）；没有时运行在 L2 停止，与缺少其他 T2 列相同。因此第 3 节可选的 TAP 补充也获取 `phot_bp_mean_mag`（只是文档说明：该补充仍须经用户同意才进行）。
6. **消光系数。** 每单位 A_V 的常数比 A_G : A_BP : A_RP = 0.789 : 1.002 : 0.589（Wang & Chen 2019, ApJ 877, 116），因此 A_BP = 1.270 A_G，E(BP − RP) = 0.523 A_G。这是对依赖颜色的 Gaia DR3 消光律的简化。
7. **消光网格。** 每个网格点模拟一次 σ = 2.7 kpc 的球对称模型，星数与 T2 样本相同，所有网格点用同一个随机种子（公共随机数（common random numbers），使网格点之间的比较不被模拟噪声主导）。|b| 箱为 [lo, hi)。某个统计量只在模拟或数据一方缺失（|b| 箱为空）时，加 100 的惩罚而不是丢弃。网格中完成的行（一个 a 值）存为断点，因此暂停最多损失一行。
8. **模拟的视差误差。** σ_ϖ 从金属丰度文件中与模拟星同在一个 0.25 mag G 箱的所有星中重采样（该箱为空时用最近的有星箱）；原始视差为 1/d − 0.02 + N(0, σ_ϖ)。
9. **T2b 拟合。** 带边界的 Nelder–Mead（xatol 10⁻⁴，fatol 10⁻⁴，每个起点至多 3,000 次求值）；扁平高斯的 σ 与 T2a 一样取 0.5–10 kpc。幂律的第一个起点为 r_c = 1 kpc、α = 3.4、q 取扁平拟合的 q；每个模型的另外四个起点在其参数范围内均匀抽取。ΔBIC 用所拟合的星数（数据中 |b| ≥ 5° 的星，或模拟的规模）。T2b 模拟的星数与数据中 |b| ≥ 5° 的星数相同。数据的幂律拟合总是计算并报告，只在第 2 步给出标签。纬度变体（3°、8°）是三个模型的点拟合加 q 的剖面，只报告。自助法对 |b| ≥ 5° 的星重采样。数据的幂律拟合与第 1 步的拟合一起进行，在第 2 步的模拟之前（第 4.10 节把第 2 步列在模拟之后）；第 2 步的模拟取自扁平高斯拟合，不依赖幂律拟合，所以这一顺序不改变任何数字。
10. **边界。** σ 离 0.5 或 10 kpc 不到 0.05 kpc 即"在边界上"（第 4.3 节）；逻辑斯蒂函数的 s 离 0.01 或 2 dex 不到 0.1% 即在边界上。
11. **T3 的自助法。** 对一个 T3 样本的 N 颗星每次重采样时，抽取 K ~ Binomial(N, n/N) 颗星，均匀地取自 [M/H] < −0.5 的 n 颗星（T3 的统计量只用到这些星）；这与对全部 N 颗星重采样同分布。箱为 [c − 0.1, c + 0.1)。
12. **逻辑斯蒂拟合。** 没有星或自助方差为零的箱不参加拟合；可用的箱少于 5 个时算作不收敛。初值：a 与 b 取前两个与后两个箱的均值，m = −1.2，s = 0.1（带边界的信赖域最小二乘（trust-region least squares），`scipy.optimize.least_squares`）。若没有一次自助重采样给出宽度，T3 (c) 为"无法判定"。T1 的总数只计 [M/H] 为有限值的行；没有 [M/H] 的行单独报告（`t1.json: counts.n_nonfinite_mh`）。
13. **w₀ 模拟。** 在主样本上进行；模拟的 J_φ/J_tot 不截断到 [−1, 1]；全部 R_apo 的变体用主样本的 w₀。每箱的弥散为数据在该星 [M/H] 所在箱中 J_φ/J_tot 的标准差。
14. **v_φ。** 取文件的 v_φ 列，或由银心坐标 x、y、v_x、v_y 计算，符号使 [M/H] > −0.5 的星的中位数为正。R0 = 8.0 与 8.4 kpc 的变体在运动学文件有日心观测量时用 astropy 由 ra、dec、ϖ + 0.02、自行与视向速度重新计算（z☉ = 0，太阳运动 (11.1, 245, 7.3) km/s），否则为"未计算"。
15. **T4。** 噪声按金属丰度文件中的每颗星抽取，连接的运动学星继承之。裁剪在每个 0.25 dex 箱中保留 T_eff 与 log g 位于百分位数之间（含端点）的星。弹性（elasticity）在 −2、−1.5 与 −1 三个截断处报告。"被上方散射主导"的标记用 0.1 dex 十次实现的计数中位数，任一方向变化超过 2 倍即标记。
16. **运行。** 种子：基础种子 20261121，每项任务一个命名的随机流；子样本用 12012。带 `?download=1` 的 Zenodo 网址已于 2026-11-21 在记录页面上确认。两个文件用 `cap_consent` 与 `budget_consent` 获取（都引用 T-021 与本研究日志）；只有设置 `PARAMS["first_download"]` 时 `allow_download` 才为真（第 8 节）。正式运行拒绝低于第 4.10 节下限的次数、部分运行（`parts` 不是全部六项）以及与预注册不同的网格大小。暂停的运行从断点继续：断点键对去掉只影响运行的键（包括 `first_download`）后的实际 PARAMS、辅助模块、去掉 PARAMS 字面量的 `run.py` 以及文件校验和做哈希。每次重启至少计算一个有断点的单元，时间守卫才可能暂停它。若 L2 发现缺少 T2 所需的列，运行停止，等待用户对可选 TAP 补充的决定（只有用户拒绝该补充时才设置 `PARAMS["t2_missing_ok"]`）。

- **首次下载。** 两个文件在用户 2026-11-21 的例外下只下载一次（T-021，`log.md`）。正式的首次运行以 `PARAMS["first_download"] = True` 启动（`ctx.http` 中 `allow_download=True`）；该次运行之后立即改回 `False` 并提交，此后的每次运行与探索都只从缓存读取文件（`budget_consent` 而不带 `allow_download`）。若缓存已经清理掉某个文件，再次下载需要再次征得用户同意（AGENTS.md 1.6）；`--refresh` 会报错而不会重新下载。
