## 1. 问题

Agazie 等人 2023（NANOGrav，ApJL 951, L8，arXiv:2306.16213；"L8"）报告了
引力波背景（GWB, gravitational-wave background）在 γ = 13/3 时的振幅 A = 2.4 (+0.7/−0.6) × 10⁻¹⁵（中位数，90%
可信区间（credible interval）），以及 γ 自由时 A = 6.4 (+4.2/−2.7) × 10⁻¹⁵、γ = 3.2 ± 0.6（中位数，5–95%），
并称 γ = 13/3 "included in the 99% credible region"。他们说这些振幅 "are compatible
with astrophysical expectations"，即与超大质量黑洞双星（SMBHB, supermassive black-hole binaries）产生的 GWB 的预期相容，
并指向配套论文 L37（arXiv:2306.16220）。利用公开的 KDE（核密度估计，kernel density estimation）自由谱（free spectrum）
表示（Lamb、Taylor & van Haasteren 2023，arXiv:2303.15442），只用 numpy：

1. **R1.** 我们在 γ = 13/3 时得到的 log10 A 后验（posterior）与 L8 的区间是否相容？
2. **R2（在近似似然下的比较，不是复现）.** γ 自由时，最小的二维 HPD（最高后验密度，highest posterior density）区域在
   什么可信水平 q 上触及 γ = 13/3？
3. **R2b（重叠汇总，不是相容性检验）.** L37 表 A1 中有多少条文献
   预言与我们 A 的 90% 可信区间重叠（这是 Lean 的 `NUM` 前提
   `num_overlap`），又有多少条包含我们的中位数？
4. **R3（描述性）.** R1 与 R2 在 2026 年的数据产品 v2.0.0
   （修复了采样器（sampler）缺陷）与 2023 年的 v1.1.0 之间变化多少？
5. **R4（描述性）.** 带低频转折（turnover）的幂律相对于
   γ = 13/3 幂律的贝叶斯因子（Bayes factor）。

Lean 论证（`argument/`）针对的是 L8 关于振幅的那句话。本研究检验其 `NUM`
前提（路径 1），并通过 R1 检验振幅输入（`stat_amp`）；不检验两个缺口
（`gap_overlap`、`gap_repr`），也不检验路径 2（holodeck 星族）。

## 2. 假设与判据

容差在此固定，看到结果后不再更改。每条判据都报告
判决、数值，以及我们对任何失败的解释。

**有效性（先于任何判据）。** 对一个数据产品，第 4 节第 1 步的结构检查（文件齐全、
数组形状一致、第一个频率在 1% 以内等于 1/T（T = 16.03 yr）、网格
均匀）必须通过，并且每个后验都必须有限且可归一化。
边缘规则适用于 R1 中的 log10 A、R2 中的 log10 A 与 γ，R3 同样，R4 中只适用于 log10 A：
在这些参数各自先验范围最外侧的 1% 内，后验质量必须少于 1%
（否则结果是由网格或先验边界驱动的）。在 R4 中，κ
与 f_b 先验边界处出现质量是预期之中的（κ → 0 以及 f_b 低于 f₁ 会使转折失效），只作报告，不作为
"不可评估"的理由。如果某项检查失败，所有依赖它的判据
都报告为 **not evaluable**（不可评估），并说明原因。

振幅：Ã、A₅ 与 A₉₅ 分别是 x = log10 A 的中位数与 5/95% 分位数的 10^x。

**R1（振幅，γ = 13/3；v2.0.0，14 个频率）。** x = log10 A 的参考分布 q(x)：
以中位数固定的两段半正态分布（two-piece half-normal），m = log10(2.4e-15)，
σ_lo = (m − log10(1.8e-15))/1.645，σ_hi = (log10(3.1e-15) − m)/1.645，密度在 x < m 时为
φ((x − m)/σ_lo)/σ_lo，在 x ≥ m 时为 φ((x − m)/σ_hi)/σ_hi（每侧概率各为
0.5，因此其 5/50/95% 分位数按构造就是 L8 的）。在 R1 网格上计算我们的后验 p 与 q 之间的
Hellinger 距离 H = sqrt(1 − ∫ sqrt(p q) dx)（两者都在网格上归一化）。若 H < 0.15 则为 **consistent with L8's interval**（与 L8 的区间相容）；否则为 **differs**（不同）。该阈值是
获取数据之前的选择（计划 014：Lamb+2023 在 NG12.5 上用自由谱重新拟合得到 H = 0.13，
一维 log10 A 边缘分布为 0.06，100 次模拟的二维 H 中位数为 0.26）。我们的中位数
与 5/95% 分位数相对于 2.4/1.8/3.1 × 10⁻¹⁵ 的比较是描述性的。

**R2（谱指数；v2.0.0，14 个频率）。** q = 二维密度超过其沿直线 γ = 13/3 的最大值的区域
的后验质量（第 4 节第 4 步）。结果就是 q 本身。
描述性分类（项目约定，始终如此标注）：q 在 [0.95, 0.997] 内为 "same
order as L8's stated tension"（与 L8 所述张力同量级）；q < 0.95 为 "weaker"（更弱）；q > 0.997 为 "stronger"（更强）。描述性内容：A 与 γ 边缘分布的中位数和
5–95% 分位数，与 L8 的 6.4 (+4.2/−2.7) × 10⁻¹⁵ 和 3.2 ± 0.6 比较；
γ = 13/3 的一维 HPD 水平；以及用 "≥" 代替 ">" 计算的 q（与 p* 相等的格点；
似然是直方图查表，因此可能出现完全相等）。

**R2b（表 A1 重叠汇总；除 Lean 绑定外均为描述性）。** 用我们 R1 的中位数 Ã
与 90% 区间 [A₅, A₉₅]：对表 A1 中第 16/84 百分位为 [P16, P84] 的每一行
（闭区间），若 A₅ ≤ P84 且 P16 ≤ A₉₅ 则为重叠；若 P16 ≤ Ã ≤ P84 则为包含中位数。
各行按所列计数（24 行；完全相同的 Rasskazov & Merritt 与 Dvorkin &
Barausse 两行分别计数），并同时报告合并相同行之后的计数。
受 Lean `NUM` 前提约束：`n_models_overlap_ci90 >= 1`。如果不成立，则 Lean `NUM`
绑定失败并予以报告；此时论证的路径 1 在我们的数据上不成立。

**R3（数据版本；描述性）。** 在 v1.1.0 上重复 R1 与 R2；报告中位数、
分位数与 q 的变化，以及两个 R1 后验之间的 Hellinger 距离。

**R4（谱形；描述性）。** 转折模型（第 4 节第 6 步）相对于
γ = 13/3 幂律的 ln 贝叶斯因子，两者都在各自先验上做网格积分。依赖先验
（L11 有此提醒）；不作判决。

## 4. 方法

1. **载入与检查**（逐个数据产品）。从缓存打开 zip，找到名称
   包含 `30f_fs{hd}` 的目录（恰好一个；否则不可评估）。读取 `freqs.npy`
   （30 个值）、`log10rhogrid.npy`（G 个值，均匀间距 db，按 10⁻⁶ 相对精度检查）和
   `density.npy`（对数密度，形状 (1, 30, G) 或 (30, G)，长度为 30 的频率轴
   在网格轴之前；任何其他形状都使该数据产品不可评估）。NaN 密度
   像 ceffyl 一样设为 −36。进行第 2 节"有效性"中的检查。zip 不可信：每个
   成员都用 50 MB + 1 字节的有界读取读入，若更长则拒绝（不信任声明的
   `file_size`）；只读取所需的三个成员（总计至多 150 MB），
   列出超过 10,000 个成员的压缩包被拒绝；名称中含
   ".." 或以 "/" 开头的成员被拒绝。
2. **似然（likelihood）**（Lamb+2023 式 8–11；ceffyl `ln_likelihood`）。对模型功率谱密度（PSD, power spectral density）S(f)，ρ_k² =
   S(f_k)/T，T = 1/f₁ 取自文件（秒），log10 ρ_k = ½ log10 ρ_k²。分箱索引
   idx_k = searchsorted(binedges, log10 ρ_k, side="left") − 1，其中 binedges = grid − db/2 再加上一个
   等于 grid[G−1] 的顶边（与 ceffyl 相同，因此最顶格是半宽，任何高于
   grid[G−1] 的值都给出 −∞）；idx < 0 时设为 0（低于网格：取最底格的密度）；
   idx ≥ G 时 ln L = −∞。
   ln L = Σ_{k < K} density[k, idx_k]（略去常数 K·ln db）。K = 14。
   幂律：S(f) = A²/(12π²) f_yr⁻³ (f/f_yr)^(−γ)，f_yr = 1/(365.25 × 86400 s)。
3. **R1.** 网格 x = log10 A 取 [−18, −14]，4001 个点（步长 0.001）；均匀先验；后验
   p ∝ exp(ln L − max)；用梯形法则归一化。中位数与 5/95% 分位数由累积
   梯形积分加线性插值得到。参考分布 q 如第 2 节，在
   同一网格上求值并在该网格上重新归一化；H 用梯形法则计算。
4. **R2.** 网格 log10 A 取 [−18, −11]（1401 个点，步长 0.005）× γ 取 [0, 7]（1401 个点，
   步长 0.005）；均匀先验（L8 附录 B）。在网格上计算后验，节点质量 w_ij =
   p_ij t_i t_j ΔxΔγ 归一化为 1，梯形权重 t 在每个轴的首尾节点为 ½，
   其余为 1（归一化、q 与边缘分布都用相同的权重）。直线密度：沿 γ = 13/3 的 p 直接在
   log10 A 网格点上求值，使用与 p_ij 相同的归一化常数；p* = 其最大值。
   q = 对 p_ij > p* 的格点求 Σ w_ij（严格不等号，按原意；"≥" 作为描述性内容报告）。
   沿 γ 轴分块计算（内存原因）。边缘分布通过
   求和得到；中位数/分位数如第 3 步；13/3 的一维 HPD 水平：γ 边缘分布中
   超过其在 13/3 处取值的部分的质量（线性插值）。
5. **R2b.** 按第 2 节的规则，使用 R1 的 A₅、Ã、A₉₅。
6. **R4.** 转折模型（Sampson、Cornish & McWilliams 2015，arXiv:1503.02662）：
   S(f) = S_PL(f; A, 13/3) / (1 + (f_b/f)^κ)。先验：log10 A ~ U(−18, −11)，log10 f_b ~
   U(−9.0, −7.5) [Hz]，κ ~ U(0, 7)；网格 701 × 61 × 71（步长 0.01、0.025、0.1），先验
   密度 1/7、1/1.5、1/7。证据（evidence）Z = ∫ L π 用梯形法则计算，以
   log-sum-exp 求值，沿 κ 分块，两个模型都略去相同的常数（K ln db）；
   ln BF = ln Z_turn − ln Z_PL，其中 Z_PL 是 γ = 13/3 幂律在 log10 A ~
   U(−18, −11)（先验密度 1/7）上、以步长 0.01 的网格积分，与转折模型的 A 轴一致。
7. **R3.** 在 v1.1.0 上执行第 1–4 步。

敏感性（可探索，见第 8 节；不属于任何判据）：低于网格时也取 ln L = −∞；
K = 30 个频率；R1/R2 网格步长减半（旋钮）；R4 网格步长（旋钮 `r4_steps`）；R4 先验
（一个探索脚本）。

需要留意的系统误差：因子化的似然忽略了频率之间的协方差，且
只在 NG12.5 上验证过；参考分布 q 由三个分位数构建，而不是
L8 的后验；KDE 是用 L8 的噪声模型和脉冲星集合构建的，我们无法改变。

2026-11-15 的运行（`python -m astrolab run 005`：首次运行含下载 12 s，缓存后 4.9 s；输入为来自 Zenodo 的 3.0 MB + 5.3 MB，已缓存；
网页：[`web/index.html`](web/index.html)）。v2.0.0 产品：目录 `ceffyl_data/30f_fs{hd}_ceffyl`，
log10 ρ 网格 −9.00 … −4.00（10,000 个点），T = 16.03 yr 取自文件。

**事后探索（post hoc）（不是预注册结果；2026-11-15）。** 使用精确的目录名
（`--set dir_key=30f_fs{hd}_ceffyl`，标签 `v1-exact-dir`），v1.1.0 给出 R1 A = 2.52 [1.91, 3.11] × 10⁻¹⁵，
相对 L8 参考分布 H = 0.143（刚好低于 0.15），以及 R2 q = 0.992、γ = 3.08 [2.52, 3.71]、
A = 7.61 × 10⁻¹⁵。v1.1.0 与 v2.0.0 的 R1 后验之间的 Hellinger 距离为 0.195：
2026 年的采样器修复使 γ = 13/3 的振幅降低约 8%，使 γ 升高约 0.17，使
重新拟合离 L8 发表的中位数稍远一些，但所有陈述在定性上都
不变。注意 v1.1.0 的网格范围为 −15.1 … −0.9，v2.0.0 的网格为 −9.0 … −4.0。

解读：在这一压缩数据产品上，使用 L8 的基准（fiducial）DMX 噪声模型（见第 6 节），重新拟合
落在 L8 的数字上（振幅在预注册的保真度之内，自由 γ 的中位数在 γ 上相差 0.05 以内、
在 A 上相差约 1%），谱指数的张力
同量级（这里 q ≈ 0.98，对比 "within 99%"），并且 Lean 论证的路径 1 在我们的数据上
成立。这些数字不触及三个缺口（`gap_overlap`、`gap_holo`、`gap_repr`；`gap_holo` 是在
