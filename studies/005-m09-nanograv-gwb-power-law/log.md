## 2026-11-15

- 独立审稿（referee）：没有代码错误，审稿人独立重算了全部数字。主要意见是系统误差与解读（README 第 6 节逐条处理）：
  - 噪声模型占主导：v1.1.0 的 DMGP（色散量变化的高斯过程，Gaussian process）自由谱上 R1 的 H = 0.312（会判"不同"）、q = 0.62、γ = 3.75；我们用探索（`--tag dmgp`）复核了这些数。结论写明以 L8 基准的 DMX 噪声模型为条件。
  - 与 L8 同期的产品是 v1.1.0（H = 0.143），近似误差的大小应以它为准。
  - R4 主要反映 γ < 13/3 的偏好：自由 γ 幂律对 13/3 的 ln BF = 1.76，转折对自由 γ 只多 0.61（`explore/r4_gamma_free.py`）。
  - 频率数敏感度：K = 30 时 H = 0.093、q = 0.993；K = 5 时 H = 0.243。
  - Lean：`mod_holo` 改标为 GAP `gap_holo`；`num_overlap` 注明以我们的区间替代 L37 自己的振幅。
  - 修正 provenance 中 v1.1.0 重复记录的问题，重跑结果相同。
- 首次运行（12 秒；Zenodo 两个压缩包共 8.3 MB，经 `ctx.http` 缓存）。结果见 README 第 5 节：
  - R1：γ = 13/3 时 A = 2.31 [1.82, 2.92] × 10⁻¹⁵，与 L8 参考分布的 Hellinger 距离（Hellinger distance）0.099 < 0.15，判定"与 L8 的区间一致"。
  - R2：与 γ = 13/3 相交的最高后验密度（HPD, highest posterior density）区域的水平 q = 0.979，描述类别"与 L8 所称张力同一量级"；自由拟合 A = 6.33 × 10⁻¹⁵、γ = 3.25，与 L8 的 6.4 × 10⁻¹⁵、3.2 几乎相同。
  - R2b：表 A1 的 24 行中 8 行与我们的 90% 可信区间重叠，Lean 的 NUM 绑定成立；5 行包含中位数。
  - R3：按预注册的目录规则，v1.1.0 不可评估：压缩包里有两个名字含 `30f_fs{hd}` 的目录（另一个是 `100fDMGP` 噪声模型的变体）。按规则如实报告，没有改动规则。
  - R4：转折模型对 γ = 13/3 幂律的 ln 贝叶斯因子（Bayes factor）= 2.37，只作描述。
- 事后探索（post hoc，不是预注册结果）：用精确目录名 `30f_fs{hd}_ceffyl` 读 v1.1.0（`explore --tag v1-exact-dir`），R1 的 A = 2.52 × 10⁻¹⁵、H = 0.143，R2 的 q = 0.992、γ = 3.08；两个版本 R1 后验之间的 Hellinger 距离 0.195。2026 年的采样器修正使振幅降低约 8%、γ 升高约 0.17，定性结论不变。
- 网页 `web/index.html`：判定表、R1 后验与参考分布、R2 二维后验与 γ = 13/3 线、表 A1 区间与我们的 90% 区间。浏览器扩展未连接，用 node 检查了脚本语法，并确认本地服务能提供页面与结果文件。
