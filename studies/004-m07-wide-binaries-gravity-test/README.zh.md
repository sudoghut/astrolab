## 1. 问题

Cookson、Banik、El-Badry 等人 2026（C26，arXiv:2602.24035）构建了 130 pc 以内干净的 Gaia DR3 宽双星
（wide binary）样本，发现标度相对速度（scaled relative velocity）ṽ = v_sky/√(GM/r_sky) 的中位数随
r_sky/r_M 保持平坦，并得出结论："Newtonian gravity is up to 1500× more likely than MOND"。我们要问：

1. **R1.** 用服务器端查询与相同的筛选条件从 Gaia DR3 重建，能否得到规模相当的样本，以及与 C26 图 8
   相似的 ṽ 中位数剖面？
2. **R2（检验）.** 使用经过校准的分箱误差（对双星对做自助法（bootstrap）重抽样），比较结果是否仍以至少 100
   的相对似然（relative likelihood）支持牛顿引力而非 MOND 阶跃？
   这就是 Lean 论证中的 `gap_err` 前提。
3. **R3（描述性）.** C26 的各项选择（投影改正、HR 筛选、距离、视差信噪比（S/N, signal-to-noise ratio）、
   ipd_frac_multi_peak、去群（degrouping）、ṽ 上限）如何影响结果？
4. **R4（描述性，可选）.** 采用 Banik 等人 2024 的选择（250 pc，G < 17）得到的中位数剖面，仅当其服务器端
   计数在预算之内时进行。

## 2. 假设与判据

**定义（在此固定）。**
- a0 = 1.2 × 10⁻¹⁰ m/s²；G = 6.674 × 10⁻¹¹（SI）；1 AU = 1.495978707 × 10¹¹ m。
- r_M = √(GM/a0)，其中 M 为该双星的总质量；x = r_sky/r_M。
- ṽ = v_sky/√(GM/r_sky)（C26 式 9）。
- MOND（修正牛顿动力学，Modified Newtonian Dynamics）预言（C26 式 2、4–8、10）：ν(g_N) = 1/(1 − exp(−√(g_N/a0)))（MLS 形式）；
  g_N,e = 1.184 a0。C26 的 x 是 r/r_M，其中三维 r ≈ r_sky√(3/2)（式 10），因此在我们的
  x = r_sky/r_M 下，内部场为 g_N,i = a0/((3/2)x²)（式 5）。g_N,t = √(g_N,i² + g_N,e²)；
  K = ∂ln ν/∂ln g_N（式 8）在 g_N,t 处取值，闭式为 K = −(y/2)e^{−y}/(1 − e^{−y})，其中
  y = √(g_N,t/a0)（介于 −½ 与 0 之间）；增益（boost）b(x) = √(ν(g_N,t)·(1 + (K/3)·tanh(0.825 g_N,e/g_N,i)^3.7))。
  一个离线单元测试检查 x → 0 时 b → 1，以及 x 很大时 b → √(ν_e(1 + K_e/3))。
  x → 0 时 b → 1（ν → 1，K → 0），因此第 j 个分箱的 MOND 模型为 A·b(x_j)，牛顿模型
  为常数 A。与 C26 一致（表 3：χ² 值 "are optimized with respect to the
  normalization in the Newtonian regime"，对每个引力模型分别如此；各自 5 个自由度），每个
  模型有自己独立的牛顿区归一化（normalisation）A——这是本研究固定的约定，也是对 C26 最
  自然的解读；归一化绑定的计算作为敏感性检验报告——
  用带分箱协方差的广义最小二乘（GLS, generalised least squares）拟合。（C26 图 8 把两条曲线都画在 0.489，仅用于展示。）x_j 是第 j 个分箱内各双星 x 的中位数（C26 图 8 用几何平均；
  两者都报告，拟合用中位数）。
- 分箱（在计算任何速度之前写定；恰好等于边界的值归入上一个分箱）：x 的边界取 C26
  表 2 各分箱中位数的几何中点：0.1057、0.2307、0.5088、1.0275、2.0902；最低分箱没有下边界
  （r_sky ≥ 1 kAU），最高分箱没有上边界（r_sky ≤ 30 kAU）。
- Δχ² = χ²_MOND − χ²_Newton，各自取最佳 A；相对似然 L = exp(Δχ²/2)。两个模型
  不是嵌套的（nested）；L 是相对似然，不是 Wilks 检验，也不是后验几率（posterior odds）。

**拟合有效性。** 每个分箱必须至少含 15 对双星。如果最外侧的分箱不足，则把
最高分箱向内合并、把最低分箱向上与相邻分箱合并，直到两端各至少有 15 对（合并后的 x_j 取合并后的中位数）。（带日期的修订，2026-11-14，在获取任何数据之前：下端的规则是在步骤 B 代码的第一闸审查（gate-1 review）指出 x < 0.1057
需要 r_sky ≈ 1 kAU 且 M ≳ 1.8 M☉、因而最低分箱可能稀疏之后加入的；C26 自己的最低分箱中位数
x = 0.073、含 368 对，对典型质量而言意味着间距低于其声明的 1 kAU，这一
不一致记录在系统误差之下。）如果仍有内部分箱不足 15 对，则该拟合不可
评估。可评估指：每个最终分箱至少含 15 对，且至少保留两个分箱；否则不给出判决。所有自由度均为 n_bins − 1（用最终的 n_bins），
包括牛顿模型的 p 值。看到计数之后，不允许任何其他合并或边界改动。15 对的下限同样适用于每个自助法
重抽样样本：任何（合并后的）分箱少于 15 对的重抽样样本要重新抽取；如果超过 5% 的抽样
被重抽，则报告该拟合无效。因此所得协方差是以固定的最终分箱和这一占据规则为条件的，而不是无条件的自助法估计。自助法协方差必须有限；如果其条件
数（condition number）超过 10⁸，则改用其对角元并加以标记；如果任何对角元不严格
为正，则拟合无效，不给出判决。

## 4. 方法

1. **双星对与去群（C24 §2.3，C26 §3.2.1）。** 只有当每个成员的邻居
   计数（A2）为 1 且该邻居就是其伴星时，才保留这一对；共用一颗星的双星对因此被去除。报告
   通过去群的 A1 双星对比例（与速度无关）；它不改变
   规则。
2. **共同距离与间距。** ϖ̄ = (σ²_ϖ2 ϖ1 + σ²_ϖ1 ϖ2)/(σ²_ϖ1 + σ²_ϖ2)（C24 式 A2），其中 σ_ϖ1 与 σ_ϖ2 是
   两颗星的 parallax_error；
   d = 1/ϖ̄；r_sky = d·θ（θ 为角距，用精确的大圆公式）。
3. **质量（C26 §4.1.2）。** 有 FLAME 质量时用之（A3），否则对每颗没有 FLAME 质量的星用 M⋆ = 10^{0.0725(M_G,⊙ − M_G)}，其中
   M_G,⊙ = 4.67（Gaia G，Vega 星等；Willmer 2018，ApJS 236, 47，表 3——在计算任何质量之前对照
   该表核实，记录在 `PARAMS` 中），M_G = G + 5 log10(ϖ̄/100)（ϖ̄ 为该双星对以 mas 为单位的
   加权视差，两颗星都用它；C26 用 d_h）；当 M⋆ < 0.7 M☉ 时加 0.05 M☉。
   M = M⋆,1 + M⋆,2。
4. **速度（C24 式 2–8，C26 §4.1.6）。** 主星（较亮的星）的空间速度由
   其 pmra、pmdec、共同视差 ϖ̄ 及其视向速度构建；它沿
   次星局地东向与北向单位矢量的分量即为预期的自行项，
   v_sky = |(κ/ϖ̄)·(μ_α*,2, μ_δ,2) − (预期项)|，κ = 4.740470464（C24 式 2–6）。使用
   主星的视向速度（RV, radial velocity）是本研究的约定（C26 §4.1.6 说一颗星的 RV 就够了，并提到
   "systemic RV"；平均 RV 版本是一个 R3 变体）；无论如何两颗星都需要 RV，因为
   C26 有 ΔRV < 10 km/s 的筛选。σ(v_sky) 以及 σ(ṽ) =
   σ(v_sky)/v_c 由完整的经透视改正的 v_sky（包括共同视差与
   透视项）对每颗星 (ϖ, μ_α*, μ_δ) 的雅可比矩阵（Jacobian）给出，用中心有限
   差分（central finite differences）计算，每颗星的 3 × 3 协方差来自 parallax_error、pmra_error、pmdec_error、
   parallax_pmra_corr、parallax_pmdec_corr 与 pmra_pmdec_corr（把 C24 附录 A 推广到
   改正后的表达式）；位置与视向速度视为精确，两颗星
   相互独立，质量误差忽略，与 C24 和 C26 一致。
5. **筛选（主样本，C26）。** d < 130 pc；1 ≤ r_sky ≤ 30 kAU；RUWE < 1.25（两颗星）；两颗星都在 HR
   带上：0.5 < BP−RP < 3.5，4 < M_G < 14，且 3.3(BP−RP) + c < M_G < 3.3(BP−RP) + c + 0.8（斜率
   3.3，高度 0.8 mag；C26 §3.2.4）。该带的位置无法从 C26 读出，因此 c 由一条
   与速度无关的规则从 A1 的星中确定：取 A1 星的去重集合（每个 source_id 一次，
   用其自身视差计算 M_G），要求 BP−RP 非空、RUWE < 1.25、自身视差 > 7.6923 mas
   （130 pc）且 |BP−RP − 1.8| < 0.05；c = median(M_G − 3.3·(BP−RP)) − 0.4，使该带以
   K 型星的星序（locus）为中心。如果符合条件的星少于 30 颗，窗口放宽一次到 |BP−RP − 1.8| < 0.15；
   若仍少于 30 颗，主样本不可评估，R1–R2 报告为未运行。c 的数值在 A1 之后、B1 之前（带日期）提交；R3 变体使用
   c ± 0.2。*带日期的说明 2026-11-16（步骤 A 之后，尚未获取任何速度列）：* c =
   1.5909（0.05 窗口内 2081 颗星；`results/step_a.json`），已作为 `PARAMS["hr_c"]` 提交。
   与速度无关的占据检查（探索脚本 `explore/occupancy_step_a.py`，筛选直到
   HR 带都相同，质量与 x 不需要速度）：各 x 分箱分别为 3、371、407、204、162、223 对，每个都是
   步骤 B 的上界（A1 ⊇ 合并后的步骤 B 双星对；RV、σ(ṽ) 与 ṽ 筛选只会去除双星对）；
   最终的合并按相同规则由步骤 B 的计数决定（在这里会把最低
   分箱并入下一个）。这些计数位于比 C26 图 8 更大的 x 处，这是系统误差中所列 x
   约定问题的一个与速度无关的迹象；没有因此改动任何边界、x 定义或合并规则
   （第 2 节禁止这样做）。步骤 A 之前，只在早先的
   速度上限守卫下运行过服务器端的双星对计数（计划 013）；没有获取过任何速度值（A1 的 `rv_method_used` 是
   第 3 节表格中列出的可用性标志，不是速度，也未被使用）。*（说明结束。）*
   两颗星都有视向速度且 |ΔRV| < 10 km/s；σ(ṽ) < 0.1；ṽ ≤ 2.5。
6. **统计。** 第 2 节的定义；自助法协方差；对 A 做 GLS 拟合。
7. **参数（run.py 中的 `PARAMS`，随结果一起保存）：** a0、分箱、自助法次数与种子、
   上述筛选值、R3 的变体开关。修改已提交的值即修订本
   预注册，需要带日期的说明。

**盲化后备方案（blinding fallback）。** 如果预注册提交错过了 2026-11-24，B1 仍在
档案库下线前获取，并且本研究通篇标注为 "unblinded"（未盲化）。

**系统误差与局限。** C26 的 x 约定有歧义：其表 2 最低分箱的中位数
x = 0.073，对典型质量、按 r_M = √(GM/a0) 而言，低于 r_sky ≥ 1 kAU 所允许的值；我们的 x 是
C26 文中所写的 r_sky/r_M，并报告各分箱计数与图 8 的对比。我们的双星对寻找方法（投影 0.5 pc 加视差一致性）是我们
对 C24 "within 0.5 pc of one another" 的解读，该表述没有说明距离是二维还是
三维；HR 带的确切位置与 C26 的分箱边界没有发表；FLAME 质量只覆盖
样本的一部分；C26 内部的样本规模不一致（1421 对 900）意味着 R1 的规模
目标本身就不确定。

## 7. 开放问题

- 为什么在相同筛选下我们的样本不到 C26 的一半（639 对 1421）：去群
  （21,949 → 8,425）与 r_sky 窗口（→ 2,825）去除了大部分双星对；C26 的 x 或 r_sky
  约定是否不同（其最低分箱意味着 r_sky < 1 kAU），可以用图 8 的各分箱
  中位数和放宽的 r_sky 下限来检验（一次探索，不作判决）。
- 分箱中位数应该用哪种误差模型：自助法误差是 MAD/√N 的 1.4–3.1 倍，
  足以把 "MOND favoured" 变成 "cannot distinguish"。一个已知牛顿速度
  并采用 C26 选择的模拟样本（mock）可以同时校准两者。
- 最外侧分箱（x ≈ 2.7）只有 24 对，使得 ipd = 0 与 HR 常数变体
  无效；不做 HR 筛选时，最低分箱（17 对）使该变体无效。
- d < 200 pc 与 C25 邻居去群诊断没有运行（第 3–4 节）。
- Lean 论证缺少一条前提：x 是在 MOND 模型的标度上计算的（审稿意见 9）；
  C26 的最低分箱与其声明的 1 kAU 下限不一致。
- 设计教训：硬性的 15 对下限加 5% 重抽上限，会使最稀疏分箱
  只有 15–20 对的变体无效。
