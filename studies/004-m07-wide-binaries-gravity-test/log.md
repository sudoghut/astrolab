- 不用速度的逐箱计数（探索脚本 `explore/occupancy_step_a.py`）：x 箱依次为 3、371、407、204、162、223 对，每箱都是第 B 步的上限；最终的合并由第 B 步的计数按同一规则决定（按这些计数，最低箱会并入相邻箱）。这些计数比 C26 图 8 偏向更大的 x，是系统误差中已列出的 x 约定问题在不用速度时的迹象；没有因此改动任何箱边界、x 的定义或合并规则。逐项截断：配对 194,157 → 去群（degrouping）37,381 → 距离 30,213 → r_sky 6,777 → RUWE（重归一化单位权误差，Renormalised Unit Weight Error）4,457 → 赫罗图带 1,370。
- 第 B 步（速度列，提交 c 之后）完成（2102 s）：21,949 对有两颗星视向速度的候选；主样本 N = 639，C26 为 1421，**R1：样本不同（different sample）**（最干净的变体 497 对 1216）。逐项截断：去群 8,425 → 距离 7,376 → r_sky 2,825 → RUWE 1,635 → 赫罗图带 712 → |ΔRV| < 10 km/s 662 → σ(ṽ) 650 → ṽ ≤ 2.5 639。牛顿归一化 0.499，C26 为 0.489。
- **R2：无法区分（cannot distinguish）**，L = 0.49（Δχ² = −1.44，牛顿 p = 0.34）；因为样本不同，标为"不是复现"。自助法（bootstrap）误差是 C26 的 MAD/√N（中位数绝对偏差，median absolute deviation）的 1.4–3.1 倍；用 C26 的误差约定时同样的中位数给出 L = 1.7 × 10⁻⁵（偏向 MOND），用 1.4826 MAD/√N 时 6.7 × 10⁻³：在我们的样本上，结果取决于误差约定而不是数据——这是 Lean 缺口 `gap_err` 的数值证据。
- R3（只作描述）：多数变体"无法区分"（L 0.13–1.16）；不去群时 L = 0.034；ipd = 0、无赫罗图截断与 c ± 0.2 的拟合无效（最外箱少于 15 对，重抽比例超过 5%）。C26 关于 150 pc 等变体的定量说法都没有复现。
