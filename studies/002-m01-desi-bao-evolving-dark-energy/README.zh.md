## 1. 问题

1. 公开的 DESI DR2 BAO（baryon acoustic oscillations，重子声学振荡）距离（均值向量与协方差（covariance））能否用本仓库自己的背景宇宙学（background）代码，
   复现论文中仅用 BAO 的 ΛCDM 约束（Ωm、h·r_d；DESI Collaboration 2025, arXiv:2503.14738, Eq. 17）？
2. 使用论文对 (θ*, ωb, ωbc) 的压缩 CMB（cosmic microwave background，宇宙微波背景）先验（compressed CMB prior）（Appendix A, Eqs. 35-36），w0waCDM 的拟合比 ΛCDM
   好多少（Δχ²_MAP，MAP 即最大后验（maximum a posteriori）；论文报告 −8.0、2.4σ，Table 6）？对先验中 ωbc 均值的两种解读
   （第 2 节，R2）分别回答。
3. 不用 CMB 时，单用 DESI，以及 DESI 分别结合 Pantheon+ 或 Union3 超新星，能否复现
   论文的 Δχ²_MAP（−4.7、−4.9、−10.1；Table 6）？

完整 CMB 的数字（−12.5、3.1σ，以及 CMB + SN 各行）不在本研究范围内：它们需要完整的
Planck 与 ACT 似然（likelihood）。DES-SN5YR 不在范围内：它的协方差（53.5 MB）超过 50 MB 的
单次下载上限。

## 2. 假设与判据

共同定义。
- Δχ²_MAP = χ²_min(w0waCDM) − χ²_min(ΛCDM)，每个极小值都在论文的先验范围内用有界多起点
  优化（bounded multi-start optimisation）求得（w0 ∈ [−3, 1]，wa ∈ [−3, 2]，w0 + wa < 0；平坦先验（flat priors），
  因此 MAP 就是受约束的最大似然；w0 + wa < 0 以
  w0 + wa ≤ −10⁻⁹ 实施）。显著性：取 N 使双侧
  高斯尾概率等于 −Δχ²_MAP 处的 χ²(2 dof) 尾概率（论文 Eq. 22）。
- 容差在此、在任何结果出来之前固定，对每种解读与每种组合都相同。
  Δχ² 容差 1.0 背后的误差预算（error budget）（写于任何结果之前）：论文把
  Δχ² 四舍五入到 0.1（±0.05）；要求优化器收敛到 0.01（见下文拟合有效性）；Aubourg 公式给出的 r_d
  相对 CAMB 精确到 0.02%，在 DESI 的精度下（合并 BAO 尺度约 0.3%）
  使 χ² 变化远小于 0.1；仅 BAO 近似（忽略辐射，
  在 z = 2.33 处 E(z) 约 5×10⁻⁴）最多使 χ² 变化约 0.1；θ* 校准因子 K 是最大的
  未知量，只由报告的 K 检查（第 2 节最后一项）界定，余下的
  容差（约 0.7）分配给它以及 z* 上 CAMB 与拟合公式的差异。对 R1，
  0.3σ 的容差在近似高斯的二参数后验上覆盖同样的实现差异。
- **拟合有效性（fit validity）（评估任何判据之前必须满足）。** 每一次拟合，包括 ΛCDM 基线，
  都必须通过下面的收敛与一致规则。每一次 w0waCDM 拟合还要
  从其嵌套的 ΛCDM 最优点（w0 = −1，wa = 0）以及论文报告的点（论文中该组合的
  w0、wa 后验均值，Table 5 / Eqs. 23-24，其他参数取
  ΛCDM 最优值）出发，因此
  必须满足 χ²_min(w0waCDM) ≤ χ²_min(ΛCDM) + 10⁻³；并且每个极小值至少有 3 个起点
  在 0.01 内一致，只计已收敛的起点（一个起点在其最后一次 Nelder-Mead 运行
  于评估次数上限内达到容差时算作收敛；一致是指 χ² 一致，一致起点之间最大的参数
  距离 `x_spread`（以先验宽度为单位）会报告但不
  作要求，因为预期存在简并方向（degenerate directions））。`n_conv`、`n_agree`、`x_spread` 和 `n_ok`
  随每次拟合保存。任一检查不通过的拟合报告为拟合失败（不作为结果），并
  优先于其他一切进行调查。
- 每条判据报告为**已复现**（reproduced）或**未复现**（not reproduced）；R2 另有
  **有条件复现**（conditionally reproduced）（见下文）。失败时报告其大小和我们最好的
  解释；事后不改动容差。

**R1（仅 BAO，ΛCDM）。** 用平坦 ΛCDM 拟合 DESI DR2 BAO（全部示踪体（ALL tracers）），对 Ωm 和
h·r_d 抽样（平坦先验 Ωm ∈ [0.01, 0.99]，h·r_d ∈ [50, 150] Mpc）：|Ωm − 0.2975| ≤ 0.0026（0.3σ）且 |h·r_d − 101.54 Mpc| ≤ 0.22 Mpc（0.3σ），使用
后验均值；并且我们的 1σ 误差（emcee 样本中央 68% 边缘区间的半宽，
即论文的约定）在 0.0086 和 0.73 Mpc 的 20% 以内。*预期：* 数据相同，
后验近似高斯，因此应当通过；如果失败，问题指向距离代码。
R1 链在烧入（burn-in）之后的长度必须 ≥ 50 个积分自相关时间（integrated autocorrelation times）τ（取各
参数中的最大值）；每个均值的蒙特卡罗误差为 σ/√N_eff，其中
N_eff = walkers × 烧入后步数 / τ，并且必须低于 0.05σ。

**R2（DESI + 压缩 CMB 先验）。** |Δχ²_MAP − (−8.0)| ≤ 1.0，分别在以下两种解读下评估：
- 解读 A（`R2.reading_A_with_nu`）：Eq. 35 的 ωbc 均值约束 ωb + ωc + ων
  （间接的数值证据，计划 010 第 2 节），以及
- 解读 B（`R2.reading_B_without_nu`）：它约束 ωb + ωc（论文在 Eq. 2 旁给出的定义）。

总体：两者都通过 → 已复现；恰好一个通过 → 有条件复现（写明是哪种
解读；结果取决于先验的参数定义）；都不通过 → 未复现。
我们不按哪种解读能命中 −8.0 来选择解读。次要项，报告但不起决定作用：
w0、wa 后验均值对比 −0.43 ± 0.22 和 −1.72 ± 0.64（Eq. 24）；它们通过雅可比（Jacobian）
依赖于抽样参数（第 4 节）。

**R3（不用 CMB）。** 对单用 DESI（目标 −4.7）、DESI + Pantheon+（−4.9）和
DESI + Union3（−10.1）中的每一项：|Δχ²_MAP − target| ≤ 1.0。三项都通过时 R3 为已复现；三项
也分别报告。

**K 检查（仅作诊断；只报告，绝不用来改动容差）。** θ* 校准因子 K 固定在
Planck 2018 参考点（第 4 节），并视为常数。报告：K 改变 θ* 的 ±1 个先验 σ 时
R2 中 Δχ²_MAP 的变化，以及我们在第二个参考点上的 100θ* 的偏差
（仅作合理性检查（sanity check））。

  ωc = 0.12011，H0 = 67.32，Σmν = `PARAMS["mnu"]`，w0 = −1，wa = 0）处 100θ* = 1.041085，CAMB 设置相同。它保留
  原来的锚点，只替换校准对宇宙学的依赖。
- **原始变体（raw variant）。** θ* = θ*_CAMB，不缩放：当前 CAMB 的绝对 θ*（即当前 Cobaya + CAMB 会

- **规则。** 对每个变体，本节的 R2 规则不变：每种解读

### 补充 2026-11-17：R2-CAMB-RD（T-030），在我们做任何用 CAMB r_drag 的拟合之前预注册

*原因。* R2-CAMB 的独立审稿（第 6 节第 2 点）指出 R2-CAMB 仍用 Aubourg 等 2015 的 r_d 公式，所以那次检查不是完全与 CAMB 一致的。T-030 还要求查明 DESI 的代码拿式 35 的 ωbc 均值与哪个量比较。*一手来源查证，2026-11-17（只读网页）：* 论文的 arXiv HTML（取回的文本中没有附录 A）、先验的来源 `cmbant/PlanckEarlyLCDM`（README 与两个 Cobaya yaml 文件：高斯的输入参数是 `thetastar`、`ombh2`、`omch2`，链中 `mnu` 固定为 0.06）以及 `CobayaSampler/bao_data`（只有 BAO 的均值与协方差文件）。在这些来源中没有找到 DESI 对压缩先验的配置；尚未查看：附录 A 的全文（PDF）、压缩方法的文献 [111]，以及 DESI 可能发布的链及其输入文件。所以这里问题仍未解决。用来源的 `gaussian_mixture` 跑 Cobaya，约束的是 ωb + ωc 对 0.14143，在 Σmν = 0.06 eV 时等于解读 A（0.14208 − 0.06/93.14 = 0.141436），且 Cobaya 的 `thetastar` 是 CAMB 的绝对 θ*：所以下面的变体中，原始-RD 加解读 A 最接近来源自己的配置。*写本补充前已看到的：* R2 与 R2-CAMB 的全部结果与两张审稿表（第 5、6 节；其中：在各最优点 `Background` 的 BAO 距离与 CAMB 相差小于 8×10⁻⁶，原始与锚定之差主要来自 N_eff 3.044 与 3.046）、每个最优点的诊断 Aubourg r_d / CAMB r_drag = 0.99971–0.99972，以及审稿人自己用 CAMB r_drag 与公式 θ* 的重拟（A 的 Δχ² 为 −6.48，B 为 −7.90，约 +0.10；我们没有重跑）。所以预期判定不变。

*问题。* θ* 与 r_d 都来自 CAMB 时，R2 各解读的判定是否改变？

*改动。* 相对于 R2-CAMB，只改 BAO 项中的声视界：r_d 取 CAMB 的 `rdrag`，与给出 θ* 的同一次 `camb.get_background` 调用（同样的设置，`camb_theta.py`）。BAO 距离 D_M、D_H 仍由 `astrolab.cosmo.Background` 计算（与 R2、R2-CAMB 相同）。与 R2-CAMB 一样有两个变体：**锚定-RD（anchored-RD）**（θ* = K_C · θ*_CAMB，用 R2-CAMB 的 K_C）与**原始-RD（raw-RD）**（θ* = θ*_CAMB）。两个变体中 r_d 都不缩放（K_C 只乘 θ*）；θ* 或 `rdrag` 非有限时拒绝该点并计数，与 R2-CAMB 中非有限 θ* 的处理相同。CAMB 调用现在在 BAO 项之前，所以拒绝计数与 R2-CAMB 的不可比较；调用 CAMB 之前的可行性检查与边界不变（CAMB 错误仍可能拒绝点，与 R2-CAMB 相同）。"相对于 R2-CAMB 同一变体"的移动用同一次运行中重跑的 R2-CAMB。其他一切（解读 A 与 B，ων = Σmν/93.14 eV，先验均值与协方差，边界，起点，种子，在任何 CAMB 调用之前的可行性检查，CAMB 错误的拒绝，有效性检查，容差）与 R2-CAMB 相同。不做 MCMC。

*规则，现在固定。* 每个变体用不变的 R2 规则（每种解读 |Δχ²_MAP − (−8.0)| ≤ 1.0）。
- 只有两个变体都有效、且都保持记录在案的各解读判定（A 未复现，B 复现）时，才写"R2 对 r_d 公式稳健"。
- 有效变体改变了某个解读的判定时，写"R2 依赖于 r_d 公式（解读 X）"（可归因于 r_d，因为 R2-CAMB 的两个变体都保持了记录在案的判定）。
- 拟合失败的变体写"无法判断（变体：拟合失败）"；有效的变体仍按自己的规则判定，"稳健"需要两个变体都有效。
在任何情况下，2026-11-14 的 R2 判定仍是记录在案的判定；这是一个敏感度结果。报告：每种解读与变体的 Δχ²_MAP、它相对于 R2-CAMB 同一变体的移动，以及解读 A 与 −8.0 的差距。事后只允许有记录、有日期的错误修正。

*运行时间。* 完整运行会重跑 R1–R3、R2-CAMB 并加上这些拟合：总共约 2 小时（上次完整运行 5,259 s）；不取数据。开关：`PARAMS["camb_rd_check"]`（需要 `camb_check`）。

## 4. 方法

- **背景（`astrolab/cosmo.py`，新的核心模块）。** 平坦 w0waCDM，暗能量用 CPL（Chevallier-Polarski-Linder）参数化；
  光子（T_CMB = 2.7255 K），N_eff = 3.044，其中一个 0.06 eV 的有质量中微子（费米-狄拉克（Fermi-Dirac）
  密度积分）和两个无质量中微子；距离 D_M、D_H、D_V 由数值积分得到。
  变量名把 ωb + ωc（`ombc`）与 ωb + ωc + ων（`omm`）区分开。
- **仅 BAO（R1、R3）。** 参数 Ωm（含中微子）与 h·r_d；在 z ≤ 2.33 处中微子
  按物质处理，忽略辐射（E(z) 的相对误差约 5×10⁻⁴）。
- **r_d（R2）。** Aubourg et al. 2015 (arXiv:1411.1074) Eq. 16 拟合公式（输入 ω_cb 与 ων
  分开）；使用前已对照原文核对公式；并与论文
  Eq. 2 以及一个声速积分做交叉检查（仅数量级）。
- **θ*（R2）。** θ* = r_s(z*)/D_M(z*)，z* 取自 Hu & Sugiyama 1996，r_s 由数值积分得到，
  再乘以常数 K，K 固定为使 Planck 2018 最佳拟合点处 100θ* = 1.041085
  （Planck 2018 VI, arXiv:1807.06209, Table 1, Plik best fit：ωb = 0.022383，ωc = 0.12011，
  H0 = 67.32；单一代码、单一精确点）。原型需要 K ≈ 1 + 1.3×10⁻³（计划 010
  第 4 节）。第二个点上的合理性检查（只报告）：同一张表的 CamSpec 列
  （后验均值 0.02229、0.1197、67.39；100θ* = 1.04106）。同一个最佳拟合点也用来
  对照 r_drag = 147.049 Mpc 检查 r_d 公式（Planck 使用 N_eff = 3.046）。
- **CMB 先验（R2）。** 在 (θ*, ωb, ωbc) 上取高斯分布，协方差取 Eq. 36，均值
  (0.0104103, 0.02223, 0.14208)；ωbc 与 ωb + ωc + ων 比较（解读 A，其中 ων = Σmν/93.14 eV，
  与论文 Eq. 7 相同）或与 ωb + ωc 比较（解读 B）。R2 中的 BAO 距离使用完整背景
  （包括辐射与中微子），而不是 R1、R3 的晚期近似。
  抽样参数：H0、ωb、ωc（+ w0、wa），平坦先验 H0 ∈ [20, 100]，
  ωb ∈ [0.005, 0.1]，ωc ∈ [0.001, 0.99]。
- **超新星（R3）。** χ² 中绝对星等以解析方式边缘化（marginalised analytically）：
  χ² = ΔᵀC⁻¹Δ − (1ᵀC⁻¹Δ)²/(1ᵀC⁻¹1)。Pantheon+：zHD > 0.01，先取协方差子矩阵再
  求逆，D_L 使用 zHD 与 (1+zHEL) 因子，列 `m_b_corr`（不是 `MU_SH0ES`）。Union3：
  分箱节点配 `mag_covmat.txt`，遵循 Cobaya 似然的列约定
  （使用前已对照其 `.dataset` 文件核对；Cobaya 只读取 `zcmb` 与 `mb`，并设
  zhel = zcmb）。
- **拟合（`astrolab/infer.py`，新的核心模块）。** 用有界多起点优化求 χ²_min：
  至少 20 个随机起点，加上嵌套的 ΛCDM 最优点和论文的点；在
  单位缩放坐标中用 Nelder-Mead，并做打磨重启（polish restarts）；非有限值和先验范围外的点
  被拒绝（有效性检查见第 2 节）；用 emcee 求后验均值（R1、R2 次要项），
  以积分自相关时间检查收敛（烧入后链长至少
  50 τ）；后验均值连同其蒙特卡罗误差 σ/√N_eff 一起报告。
- **测试。** 对 `cosmo`（极限、Planck 参考点、K）和 `infer`
  （解析边缘化对照暴力网格、Δχ² → σ 转换：12.5 → 3.1σ，
  8.0 → 2.4σ）做离线单元测试。
- **来自 CAMB 的 θ*（补充 2026-11-16）。** 需要 `camb`（不在基础安装命令中；没有它时把
  `camb_check` 设为 false）。R2-CAMB 见第 2 节；代码在 `camb_theta.py`，结果
  在 `results/r2_camb.json`；由 `PARAMS["camb_check"]` 开关（必须已安装 CAMB）。
- **已知局限。** 没有完整的 CMB 似然；R2 本身的 θ* 通过校准后的拟合公式得到，不是 CAMB
  （CAMB 只进入 R2-CAMB 敏感度检查，补充 2026-11-16）；Wilks 校准
  （Wiki `gap_regular`）在此与论文一样是假定的，只作探索（第 8 节）。

### R2-CAMB（补充 2026-11-16，T-022）

### DESI 对压缩先验的配置（T-041，事后，2026-11-18）

只读页面（没有下载链）。DESI 公开的 DR2 宇宙学发布（`data.desi.lbl.gov/public/papers/y3/bao-cosmo-params/`）
包含"DESI BAO + CMB-compressed-theta-ombh2-ombch2"在 ΛCDM（`base`）与 w0waCDM（`base_w_wa`）下的 Cobaya 配置
（`chain.updated.yaml`，链接见英文版；ΛCDM 文件的相应行相同）：
- 似然（likelihood）`CMB_standard_compression_PR4` 的观测量（observables）是 `thetastar, ombh2, ombch2`，均值
  0.01041027、0.02223208、0.14207901，协方差给到 9 位有效数字（ωbc 为 1.48841714 × 10⁻⁶），它的 `input_params`
  只有 `ombh2` 和 `omch2`，所以观测量 `ombch2` 应是似然由它们构造的；
- `omch2` 是导出参数（derived parameter），定义为 `omm*(H0/100)**2 - mnu / 93.14 - ombh2`，即不含中微子密度；
  `mnu` 固定为 0.06；CAMB 1.5.4，一个有质量中微子，N_eff = 3.044。

所以似然接收 ωb 与 ωc，但不接收 ων：**按配置的证据，解读 B 是 DESI 的约定**。似然的 Python 源码不公开，
构造 `ombch2` 的那一行没有看到，因此不能排除它在内部加上一个常数 ων（固定 0.06 eV 时为 0.000644），那就是解读 A。
我们的解读 B 复现了 −8.0（公式为 −8.01，CAMB 各变体为 −7.90 到 −8.13），这使 B 成为可能性大的解读。
事后；记录的判定"有条件复现（解读 B）"保持不变。

仍未解决的是先验均值本身。来源链 `cmbant/PlanckEarlyLCDM` 给出 ωb + ωc = 0.14143，而 DESI 的似然（名为"PR4"）
用 0.14208，高 0.00065（0.53σ），恰好是 0.06 eV 的 ων。DESI 的均值是来自不同的输入，还是在压缩这一步加上了
ων，从这些文件无法判断。论文为压缩引用文献 [111]，这里没有确认是哪篇：arXiv HTML 在参考文献与附录 A 之前
就中断了，PDF 又超过读取页面工具的大小上限。未查看：附录 A 正文、文献 [111]。
