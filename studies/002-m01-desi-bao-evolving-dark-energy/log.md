## 2026-11-18

### DESI 对压缩先验的配置（T-041，事后）

- 只读页面：DESI 公开的 DR2 宇宙学发布中，"DESI BAO + CMB-compressed-theta-ombh2-ombch2"的 Cobaya 配置（`chain.updated.yaml`，ΛCDM 与 w0waCDM）显示压缩 CMB 似然只接收 `ombh2` 与 `omch2`，而 `omch2 = omm·h² − mnu/93.14 − ombh2` 不含中微子；均值 0.14207901。所以按配置的证据，解读 B 是 DESI 的约定；但似然源码不公开，构造 `ombch2` 的那一行没看到，不能排除它在内部加上常数 ων（那就是解读 A）。我们的解读 B 复现 −8.0，使 B 可能性更大。
- 记录的判定"有条件复现（解读 B）"不变，其条件得到 DESI 配置的支持（非证明）。仍未解决：DESI 的均值比来源链 `cmbant/PlanckEarlyLCDM` 的 ωb + ωc（0.14143）高 0.00065，恰为 0.06 eV 的 ων；论文附录 A 正文与文献 [111] 未能读到（arXiv HTML 在参考文献前中断，PDF 超过读取工具的大小上限）。

### R2-CAMB-RD：θ* 与 r_d 都取自 CAMB（T-030）

- 2026-11-17 先在论文 HTML、`cmbant/PlanckEarlyLCDM`、`CobayaSampler/bao_data` 中查找 DESI 压缩先验的配置（只读页面），没有找到；于是预注册 R2-CAMB-RD（README 第 2 节补充），预注册与代码各过双闸审查。
- 正式运行 5189 s：R1、R2、R3、K 检查与 R2-CAMB 的数字与此前完全相同。
- **结论（按预注册规则）：R2 对 r_d 公式稳健。** 锚定-RD（anchored-RD）：A −6.49，B −7.90；不缩放-RD（raw-RD）：A −6.60，B −8.03；相对 R2-CAMB 同一变体都移动约 +0.10，与 R2-CAMB 审稿人的估计一致。判定仍为 A 未复现、B 复现。
- 独立审稿（事后，post hoc；已复核）：没有改变标签的错误，8 个最优点上重算的 χ² 与结果完全相同。+0.10 是 r_d 的常数缩放（Aubourg 公式是 CAMB r_drag 的 0.99971，约 −0.020% 是公式误差，−0.007% 来自 N_eff 3.044 对 3.046），对两种解读作用相同，不能解释 A/B 分歧；"稳健"只在这个窄的意义上成立。
- 解读 A 与 −8.0 的差距仍约 1.4–1.5；DESI 代码怎样使用式 35 的均值仍待一手来源（附录 A PDF、文献 [111]、DESI 链发布）。

## 2026-11-16

### R2-CAMB：用 CAMB 核对 θ* 标定（T-022，计划 020）

- 用户同意在项目 venv 中安装 CAMB（宇宙学线性理论代码，Code for Anisotropies in the Microwave Background；camb 2.0.5，不是数据下载；Anaconda base 未动）。
- 先写预注册附录（README 第 2 节，R2-CAMB），再写代码；两个环节各过双闸审查。闸门 1 第 1 轮指出：只用"锚定（anchored）"变体下结论，而它是在已知原始 CAMB 偏移方向（+0.29 个先验 σ，预计使解读 A 移动约 −0.1）之后选的，偏向"稳健"的结论；改为锚定与原始（raw）两个变体都进入结论。代码闸门 2 指出不能把所有异常当作被拒绝的点：只计数 CAMB 自身的错误，其他异常终止运行。
- 冒烟测试发现 1 个错误（CAMBparams 没有 `neutrino_hierarchy` 属性），修正后正式运行（5259 s）：R1、R2、R3 与 K 检查的数字与 2026-11-14 完全相同。
- **结论（按预注册规则）：R2 对 θ* 标定稳健。** 锚定变体：解读 A −6.59（移动 −0.007），B −8.01（−0.002）；原始变体：A −6.71（−0.119），B −8.13（−0.125）；逐解读判定都不变（A 未复现，B 复现）。
- 诊断：12 个最优点上，标定公式的 100θ* 与锚定 CAMB 相差 −0.012 到 −0.048 个先验 σ，比独立审稿认为可能的约 1σ 小约 20 倍；Aubourg 公式的 r_d 是 CAMB r_drag 的 0.99971–0.99972。
- 认识的变化：R2 两种解读的分歧不是 θ* 标定造成的，R2 确实依赖压缩先验中 ωbc 的约定。记录的 R2 判定不变。
- **独立审稿（只看预注册、代码与结果）的主要发现（事后，post hoc）**：压缩先验的来源 `cmbant/PlanckEarlyLCDM`（我们自己读了它的 README 并复算）给出 (θ*, ωb, ωc) 的高斯分布；变换到 (θ*, ωb, ωb + ωc) 后协方差与论文式 36 逐位相同，但 ωb + ωc 的均值是 0.14143，而式 35 印的是 0.14208，差 0.00065 正是 0.06 eV 中微子的 ων。所以**解读 A 才是来源先验的忠实形式**，解读 B 等于把均值移动 +0.53σ。按 A，我们的 Δχ² 约 −6.6（审稿估计换用 CAMB 的 r_drag 再加约 +0.1），论文为 −8.0。预注册的判定仍记为"有条件复现（解读 B）"，但 B 的吻合可能是巧合，也可能反映 DESI 代码如何使用这个均值；需要 DESI 的似然配置才能判断，登记为 T-030。其他意见：r_d 仍用 Aubourg 公式（审稿估计换成 CAMB 的 r_drag 使 Δχ² 移动约 +0.1，不改变判定）；原始与锚定变体之差几乎全来自 N_eff 3.044 与 3.046；检验的统计功效有限。审稿表见 README 第 6 节。

## 2026-11-14

### 独立审稿（referee）与修订（T-004，计划 010 环节 5）

独立审稿子智能体只看到预注册（README 第 1–4 节）、代码、结果、Lean 论证与"引文—类型—内容"对照表以及论文，不看我们的结论。没有发现会改变判定的代码错误；判据按预注册执行。主要意见：

- **R2 两种解读的分歧可能落在系统误差之内**：θ* 标定每改变一个先验 σ，Δχ² 移动约 0.4；在 K + 1σ 时解读 A 只差 0.02 就进入容差；标定在拟合点（ωc 0.117–0.120）处随宇宙学参数的变化没有测过，可能达到约 1σ。接受为已知局限，结论改为"不判断 DESI 的先验用哪种约定"；用 CAMB 在拟合点核对 θ* 登记为 T-022（安装 CAMB 需用户同意）。
- **式 2 指向解读 A**：式 2 把 ωbc 归一到 0.1432，等于包含 0.06 eV 中微子的 Planck ωm，所以解读 B 不能简单说成"论文的定义"。相关措辞已改。
- 其他：K 检查改用 20 个起点并重跑；测试不再断言诊断性的 K 检查数值；Lean 注释补充 `mod_sig` 的单调性、`Challenged` 的命名、`gap_regular` 的先验截断。审稿表见 README 第 6 节。

### 运行与结果（T-004，计划 010 环节 4）

- 正式运行（最终一次 1717 s，输入 33.9 MB，全部经受守卫的通道取数并缓存在系统缓存目录）。所有拟合都通过预注册的有效性检查。
- **R1 复现**：只用 BAO 的 ΛCDM，Ωm = 0.2979 ± 0.0086（偏离 +0.05σ），h·r_d = 101.52 ± 0.73 Mpc（−0.03σ）。
- **R3 复现**：不含 CMB 的 Δχ²_MAP：只用 DESI −4.65、加 Pantheon+ −4.86、加 Union3 −10.03（论文 −4.7、−4.9、−10.1）。
- **R2 有条件复现（解读 B）**：压缩 CMB 先验的 ωbc 均值按 ωb + ωc 解读（式 2 旁正文写明的定义；但式 2 的归一指向 A，见上）时 Δχ² = −8.01，后验均值 w0 = −0.437 ± 0.226、wa = −1.69 ± 0.66，与论文几乎一致；按计划阶段起初倾向、与 B 并列预注册的解读 A（含 ων，只有间接数值证据）时 Δχ² = −6.59，未复现。K 检查（θ* 标定整体改变 ±1 个先验 σ）只让 Δχ² 移动约 ±0.4，常数平移弥合不了两种解读之间 1.4 的差（但标定随宇宙学参数的变化没有测过，见上面的独立审稿）。判定按预注册记录，不事后更换解读。环节 1 闸门 2 坚持两种解读并列判定，避免了把未经证实的解读当作唯一判据。
