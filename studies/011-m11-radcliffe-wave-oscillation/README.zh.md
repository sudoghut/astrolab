# M11 Radcliffe 波：年轻星团组成的波在振荡吗？

> English: [README.md](README.md)（M11 Radcliffe Wave: is the young-cluster wave oscillating?）。以英文 `README.md` 为准（预注册与判据的权威文本）；本文件是它的中文译本，节号与表格一一对应，英文改动时在同一个 PR 中同步修改。网页在线版：[https://sudoghut.github.io/astrolab/studies/011-m11-radcliffe-wave-oscillation/web/](https://sudoghut.github.io/astrolab/studies/011-m11-radcliffe-wave-oscillation/web/)。

> 第 1–4 节须在写 `run.py` 之前完成（预注册，pre-registration）；之后只能带日期注明理由地修改。

## 1. 问题

Konietzka 等 2024（Nature 628, 62；arXiv:2402.12596；下称 K24）用阻尼波模型拟合 Radcliffe 波沿线年轻星团的位置与竖直速度（以及分子云的位置），结论是：波像行波（travelling wave）一样穿过银盘振荡；行波相对驻波（standing wave）"strongly preferred"；拟合出的振荡频率可以测量本地中平面密度与太阳的竖直振荡周期。我们只用 K24 的两张公开表来问：(1) 他们发表的拟合能否复现（T1、T2）；(2) 用不带有我们在论证分析中找出的弱点的检验，数据对行波相对驻波的偏好有多强（T3、T4、T5）；(3) 在合理改变分析选择时，这些答案是否不变（T6）；(4) ¹²CO 速度对竖直运动能说明多少（T7）；(5) 拟合出的竖直频率是由数据还是由先验决定（T8）。这些检验来自 Wiki 文章第三部分（[Study-011](https://github.com/sudoghut/astrolab/wiki/Study-011-radcliffe-wave-oscillation)），那里把每项检验对应到 Lean 拆解（`argument/Argument.lean`）中的前提或缺口。本节与第 2–4 节写于 2026-11-21，在任何模型拟合之前；此前接触数据的仅限于读取两张表的列名、行数与取值范围（Wiki 第三部分）。

## 2. 假设与判据

受检验的假设是 K24 的解读：年轻星团的 z 与 v_z 在采用的银河系引力势中遵循同一个行波（B 接近 1），而不是驻波（B = 0.5）。

除另有说明外，后验区间为中心 68%（第 16–84 百分位），自助法（bootstrap）区间为 95%。"K24 1σ"指其扩展数据表 2 中印出的非对称 16–84% 区间。每项检验有自己的标签；无法评估的检验报告为"不可评估"并写明原因。

| 检验 | 量 | 标签（判定规则） |
|---|---|---|
| **T1** 复现 | 我们对第 (4) 列（星团，B = 1）与第 (6) 列（云 + 星团，B = 1）得到的 A、p、δ、s₀、γ、φ 的后验中位数 | 每一列：6 个中位数中至少 5 个落在 K24 的 16–84% 区间内为**复现**；3–4 个为**部分复现**；至多 2 个为**未复现**。同时报告：锚点、以 σ 为单位的差异，以及我们的内点集合与表中 `inlier` 标记的重叠 |
| **T2** B 自由 | B 的后验（第 (5) 列的设置，ω₀t 自由），在 [0, 1] 上，不折叠 | 只报告，不给标签：中位数与 16–84%，与 0.84（+0.07/−0.06）比较；P(B > 0.95)；P(B < 0.5) |
| **T3** 嵌套似然比 | B 自由模型的最大似然，以及在 B = 0.5 与 B = 1（ω₀t = 0，在那里它并入 φ）处的剖面似然；2ΔlnL | **驻波**：p 取自 χ²₁，并用参数自助法检查（从 B = 0.5 拟合抽取 100 个模拟；若自助法 p 与 χ²₁ 的 p 落在某个阈值的两侧，用自助法 p）：p < 0.001 为**强烈排除驻波**；0.001 ≤ p < 0.05 为**排除驻波**；p ≥ 0.05 为**不排除驻波**。100 个模拟时自助法 p 只能分辨到 0.01；此时仅当没有任何模拟超过观测的 2ΔlnL 时，p < 0.001 才由 χ²₁ 判定。**纯行波（B = 1）**：p 取自 χ²₂，同样用从 B = 1 拟合抽取的 100 个模拟检查：p < 0.05 为**受到否定**，否则为**未受否定** |
| **T4** 相位弥散 | 对 B = 0.5 拟合的内点计算 R = \|exp(2iφ_k) 的平均\|，φ_k = arctan(z_k ω_k / v_z,k)；p = 1000 个驻波模拟中 R ≤ R_obs 的比例；功效 = 从 B = 1 拟合（以及作为报告的 B 自由拟合）抽取的 1000 个模拟中 p < 0.01 的比例 | p < 0.01 且功效 ≥ 0.8 为**相位排除驻波**；p > 0.05 且功效 ≥ 0.8 为**不排除**；其他情况（包括功效 < 0.8）为**无法判定** |
| **T5** 不预设关系地看 z 与 v_z | 由共用 k 的拟合得到 b̂（2B − 1 的估计，符号取 K24 的传播方向）；由 k 分开的拟合得到 k_z/k_vz；95% 自助法区间（1000 次重抽样，Λ 从只用云的拟合的后验中抽取） | **波长**：k_z/k_vz 的区间落在 [0.8, 1.25] 内为**一致**；完全落在其外为**不同**；其他为**无法判定**。**b̂**（b_T = 0.4，即 B = 0.7）：区间完全高于 0.4 为**沿 K24 方向的行波成分占主导**；完全低于 0.4 为**沿 K24 方向的行波成分不占主导**；其他为**无法判定**；区间完全低于 −0.4 时另行报告为反向传播。波长为"不同"时为**不适用**。已知答案检验（在 B = 0.5、0.84 与 1 各注入 20 个模拟；每次注入取 b̂ 为中位数的那个模拟）的通过条件：其区间在 B = 0.5 时覆盖 0，在 B = 0.84 时覆盖 0.68，在 B = 1 时完全高于 0.4；不通过时 b̂ 的标签为**无法判定**，并报告偏差 |
| **T6** 稳健性 | 在第 4.6 节的每个变体下 T3（驻波）、T4 与 T5（b̂）的标签 | 没有任何变体改变这三个标签中的任何一个为**稳健**；否则为**脆弱**，并列出改变的变体与标签。变为或变出"无法判定"或"不可评估"也算改变 |
| **T7** CO | 三个版本下 ¹²CO 速度的 χ²（T1 第 (6) 列模型；同一模型令 v_z = 0；B = 0.5 的拟合），每个版本各自拟合内禀弥散 | T1 版本的 χ² 比另外两个都低至少 9 为**CO 偏好行波**；否则为**CO 无法区分**。（预期：v_z 对 v_LSR 的贡献最多约 3 km/s，所以"无法区分"很可能） |
| **T8** 引力势 | 放开 ω₀、μ₀、r₀（第 (7) 列的设置）时 ω₀ 的后验，分别用 K24 的先验与宽的均匀先验（ω₀ 30–150 km s⁻¹ kpc⁻¹、μ₀ 0.3–3 kpc⁻¹、r₀ 1–10 kpc） | 在宽先验下，ω₀ 后验 16–84% 的半宽小于 K24 先验半宽的一半（以 ln ω₀ 计：0.085），且两种先验下的中位数相差小于 0.5σ（σ 取宽先验后验 16–84% 宽度的一半），为**由数据决定**；两条都不满足为**由先验决定**；其他为**部分由数据决定**。报告两种先验下的 ρ₀ = ω₀²/(4πG) 与太阳的竖直振荡周期 |

**总体解读**按标签机械地形成："**这批数据支持 K24 的行波解读**"，当且仅当 T1 第 (4) 列为复现或部分复现、T3 为排除或强烈排除驻波、T4 为相位排除驻波、T5 为行波成分占主导，且 T6 为稳健；"**不支持**"，当 T3 为不排除驻波且 T5 为行波成分不占主导；其他情况为"**混合**"，并列出哪些检验支持、哪些不支持。T7 与 T8 单独报告，不进入总体解读。

**什么会改变我们对方法的看法。** 如果 T1 两列都"未复现"，其余检验照常运行并报告，但标注"基于我们未能与 K24 拟合一致的复现"，README 写明总体解读针对的是我们对模型的实现，而不是 K24 的实现。

## 4. 方法

### 4.1 模型（K24 式 1–13）

- 引力势 Φ(z, r) = ½ ω₀² exp[(r☉ − r)/r₀] (z² − μ₀² z⁴)，r☉ = 8.4 kpc；采用值 ω₀ = 74 km s⁻¹ kpc⁻¹、r₀ = 3.7 kpc、μ₀ = 1.3 kpc⁻¹（只在 T8 中放开）。ω(z_max, r) 取自式 3，完全椭圆积分用 `scipy.special.ellipk`（参数 m 的约定，m = k²），z_max = |ζ(s)|（与 K24 相同）。r(s) = √((r☉ − x(s))² + y(s)²)，坐标为日心银道坐标，x 指向银心。
- 平面内基线：经过锚点 (x₀, y₀)（u = 0）、(x₁, y₁)（u = 0.5）、(x₂, y₂)（u = 1）的二次拉格朗日曲线 P(u)，在 u ∈ [−0.2, 1.4] 上取 2000 个点；s 为从 u = 0 起算的弧长（u < 0 时为负）。锚点的先验取扩展数据表 1；曲线延伸过第三个锚点，因为 K24 的模型一直延续到天鹅座 X。
- Λ(s) = s/(p − γs)（式 6），只在 p − γs > 0 的格点上使用（p − γs ≤ 0 的格点不参与最近点搜索）；ζ(s) = −A [1 + ((s − s₀)/δ)²]⁻¹（式 9）；z(s)、v_z(s) 取式 4–5。
- 星团的距离向量 d = (x, y, z, v_z/ω₀) − 最近格点处的模型值，v_z/ω₀ 以 pc 计（ω₀ = 74，T8 中用拟合的 ω₀）；云用 3 维向量。似然取式 13（星团）与式 11（云），σ = 47 pc 固定，离群函数 C(d/σ) = (Σₙ tanh((dₙ/σ)²))^½。某个星团只要有一个分量 |dₙ|/σ > √3，即某个 n 满足 tanh((dₙ/σ)²) > tanh(3)，就是离群点（K24 的规则）。
- 核密度权重：在 s 上的高斯核密度，带宽 100 pc（约为波长度的 3–4%）；每个天体的权重与其 s 处的密度成反比，在各自集合内归一化为天体数。权重用每个天体在 K24 第 (6) 列最佳拟合下的 s 计算一次，抽样时保持不变。
- 先验：扩展数据表 1，有三处是我们的理解。(i) ω₀t：MCMC 中为 U(−π/2, π/2)；最大似然拟合中按周期处理（第 4.3 节）。(ii) 印出的 ln(μ₀ pc) ~ N(−1.346, 0.25) 给出 μ₀ ≈ 0.26 pc⁻¹，在物理上不合理；我们理解为 ln(μ₀ · kpc) ~ N(ln 1.3, 0.25)，以采用值 1.3 kpc⁻¹ 为中心。(iii) ln(ω₀ km⁻¹ s pc) ~ N(−2.4, 0.17) 按印出的使用（ω₀ ≈ 91 km s⁻¹ kpc⁻¹）。

### 4.2 拟合

- T1、T2、T8 的抽样器：emcee，48 个行走者（walker），6000 步，丢弃前 2000 步；报告接受率与自相关时间；若链长短于 50 个自相关时间，标记该拟合并以两倍步数重跑。
- 最大似然拟合（T3；以及 T4–T7 用到的拟合）：从 20 个起点中取最好的（MCMC 中位数加 19 个先验抽样），先 Nelder–Mead 再 L-BFGS-B，以先验的支撑集为边界；同时报告最大后验（MAP）值。
- 各拟合的设置：第 (3) 列 只用云，B = 1，ω₀t = 0；第 (4) 列 只用星团，B = 1，ω₀t = 0；第 (5) 列 只用星团，B 与 ω₀t 自由；第 (6) 列 云 + 星团，B = 1，ω₀t = 0；第 (7) 列 同 (6)，再放开 ω₀、μ₀、r₀。

### 4.3 T3 与 T4

- T3：对其他所有参数求剖面，分别在 B = 0.5 与 B = 1（ω₀t = 0）处；B 自由的最大值中 ω₀t 在 (−π, π] 上按周期处理。自助法模拟从拟合的零假设模型抽取数据：每个星团最近点处拟合的 z 与 v_z，加上全部四个分量上 σ = 47 pc 的高斯噪声与该星团在 z、v_z 上的测量误差；每个模拟都重新拟合两个模型。
- T4：模拟保留观测星团在 B = 0.5 拟合中的模型位置，加入与 T3 相同的噪声；每个模拟星团在 B = 0.5 拟合的曲线上重新求最近点（不重新拟合）。一个变体改为对该拟合的残差向量重抽样来抽取噪声。

### 4.4 T5

- 基线与 Λ(s) 取自第 (3) 列只用云的后验；每个星团的 s 为它在 x–y 平面上向基线的投影；最近点落在格点端点的星团剔除并计数。两次拟合用全部 125 个星团（T6 的变体适用），每个分量取 A·ζ̃(s)·sin(2πkΛ(s) + ψ)，A ≥ 0、k ∈ [0.3, 3]，用加权最小二乘，误差为测量误差与 47 pc 弥散的平方和开方；ζ̃ 为只用云的包络形状除以其峰值。k 分开的拟合：k_z 与 k_vz 分开；共用 k 的拟合：只有一个 k。
- b̂ = 矩阵 [[A_z cos ψ_z, A_z sin ψ_z], [A_v cos ψ_v, A_v sin ψ_v]] 的奇异值之比 σ_min/σ_max，乘以行列式的符号；在 K24 的模型中，它对任何 ω₀t 都等于 2B − 1。v_z 除以 ω(s)，ω(s) 以只用云的包络作为 z_max 计算。
- 自助法：对星团做 1000 次重抽样，每次从只用云的后验中抽取 Λ。已知答案检验在拟合数据之前运行：在星团的 s 处注入 B = 0.5、0.84 与 1，每次 20 个模拟，ω₀t 取自 B 自由的拟合，其他参数取自第 (6) 列的拟合，噪声与 T3 相同。

### 4.5 T7

把每个云最近点处模型的三维速度投影到视线方向（式 14）。平面内部分为平直自转曲线的银河系自转（V_c = 242 km/s，即 K24 为其采用的引力势给出的值；r☉ = 8.4 kpc；相对于 LSR），加上整体平移速度 Θ₂；Θ₂ 为 T1 第 (6) 列内点星团扣除自转后 (v_x, v_y) 残差的核权重平均。每个云的误差为 (vr84 − vr16)/2；每个版本的内禀弥散用最大似然拟合。

### 4.6 稳健性变体（T6）

每个变体都重跑 T3、T4 与 T5（改变内点规则的变体在 T3 与 T4 中同样改变）：(1) 离群规则改为按分量 3σ，而不是 √3σ；(2) 不用离群模型（普通高斯似然）；(3) 不用核密度权重；(4) 核带宽 50 pc；(5) 核带宽 200 pc；(6) 太阳运动 w☉ = 7.25 km/s 而不是 7.8（每个 v_z 加 0.55 km/s）；(7) 去掉猎户座：`name` 或 `reference` 标为猎户座成员的星团；若表中无法识别，则用 180 < l < 220 度、−25 < b < −5 度的星团（这个范围在读取数据之前在此定义）；(8) 每次去掉一个 `reference` 星表（共 7 个；少于 5 个星团的合并为一次去掉）；(9) 只用 sigmavz 低于中位数的星团。

### 4.7 开销与顺序

约 25–40 次最大似然拟合、5 次 MCMC 拟合，以及模拟（T3 重新拟合 200 次，T4 计算 2000 次，每次 T5 运行做 1000 次自助法拟合）。预计在单核上需要几小时。若短时间的计时运行表明总时长会超过 10 小时，在正式运行前减少模拟次数，作为带日期的修订记录，绝不在看到任何检验结果之后再改。正式运行要等到没有其他研究在运行时进行。T5 的已知答案检验最先运行。结果文件（`results/`）：`t1_t2.json`、`t3.json`、`t4.json`、`t5.json`、`t6.json`、`t7.json`、`t8.json` 与 `summary.json`，每个都小于 1 MB（链经过稀疏或汇总）。

### 4.8 已知但不检验的系统误差

独立的速度数据（Zhu 等 2024；Bobylev 等 2025）：不在本研究范围内（开放问题）。在 K24 没有写明之处我们的选择（核带宽、曲线参数化、最近点格点、μ₀ 先验的理解）：T6 覆盖了其中一部分。表中的 `inlier` 标记来自 K24 的最终拟合；我们不用它做选择，只用于比较。
