# M11 Radcliffe 波：年轻星团组成的波在振荡吗？

## 1. 问题

Konietzka 等 2024（Nature 628, 62；arXiv:2402.12596；下称 K24）用阻尼波模型拟合 Radcliffe 波沿线年轻星团的位置与竖直速度（以及分子云的位置），结论是：波像行波（travelling wave）一样穿过银盘振荡；行波相对驻波（standing wave）"strongly preferred"；拟合出的振荡频率可以测量本地中平面密度与太阳的竖直振荡周期。我们只用 K24 的两张公开表来问：(1) 他们发表的拟合能否复现（T1、T2）；(2) 用不带有我们在论证分析中找出的弱点的检验，数据对行波相对驻波的偏好有多强（T3、T4、T5）；(3) 在合理改变分析选择时，这些答案是否不变（T6）；(4) ¹²CO 速度对竖直运动能说明多少（T7）；(5) 拟合出的竖直频率是由数据还是由先验决定（T8）。这些检验来自 Wiki 文章第三部分（[Study-011](https://github.com/sudoghut/astrolab/wiki/Study-011-radcliffe-wave-oscillation)），那里把每项检验对应到 Lean 拆解（`argument/Argument.lean`）中的前提或缺口。本节与第 2–4 节写于 2026-11-21，在任何模型拟合之前；此前接触数据的仅限于读取两张表的列名、行数、取值范围，以及星团表 `reference` 与 `inlier` 两列的取值计数（Wiki 第三部分）：89 个内点、36 个离群点；7 个来源星表，分别有 43、37、23、15、5、1、1 个星团。

## 2. 假设与判据

受检验的假设是 K24 的解读：年轻星团的 z 与 v_z 在采用的银河系引力势中遵循同一个行波（B 接近 1），而不是驻波（B = 0.5）。

除另有说明外，后验区间为中心 68%（第 16–84 百分位），自助法（bootstrap）区间为 95%。"K24 1σ"指其扩展数据表 2 中印出的非对称 16–84% 区间。N 个模拟中有 k 个至少与数据一样极端时，自助法 p 值为 p_boot = (1 + k)/(1 + N)。每项检验有自己的标签；无法评估的检验报告为"不可评估"并写明原因。

| 检验 | 量 | 标签（判定规则） |

| **T3** 嵌套似然比 | B 自由的最大值与 B = 0.5 处剖面似然之间的 2ΔlnL（参考分布 χ²₁），以及与 B = 1、ω₀t = 0（ω₀t 在那里并入 φ）处之间的 2ΔlnL（参考分布 χ²₂）；各用从零假设拟合抽取的 N 个模拟校准（第 4.3 节）：校准后的 p = 2ΔlnL × (d / m) 的 χ² p 值，d 为参考分布的自由度，m 为模拟 2ΔlnL 的平均（Bartlett 型重标度；m = 0 时校准后的 p 不可评估）；另报告 p_raw（未校准的 χ²）、p_boot，以及所有拟合的内点集合及其重叠 | **强烈排除驻波**：校准后的 p 与 p_raw 都小于 0.001，且没有模拟达到观测的 2ΔlnL；**排除驻波**：不属于"强烈"，且校准后的 p 小于 0.05、p_boot 小于 0.05；其他为**不排除驻波**。**纯行波（B = 1）受到否定**：其校准后的 p 小于 0.05 且 p_boot 小于 0.05；否则为**未受否定** |

**总体解读**按标签机械地形成："**这批数据支持 K24 的行波解读**"，当以下各项都成立时： T1 第 (4) 列为复现或部分复现、T3 为排除或强烈排除驻波、T4 为相位排除驻波、T5 为行波成分占主导，且 T6 为稳健；"**不支持**"，当 T3 为不排除驻波且 T5 为行波成分不占主导；其他情况为"**混合**"，并列出哪些检验支持、哪些不支持、哪些无法判定或不可评估。T7 与 T8 单独报告，不进入总体解读。

**什么会改变我们对方法的看法。** 如果 T1 两列都"未复现"，其余检验照常运行并报告，但标注"基于我们未能与 K24 拟合一致的复现"，README 写明总体解读针对的是我们对模型的实现，而不是 K24 的实现。

## 4. 方法

### 4.1 模型（K24 式 1–13）

- 引力势 Φ(z, r) = ½ ω₀² exp[(r☉ − r)/r₀] (z² − μ₀² z⁴)，r☉ = 8.4 kpc；采用值 ω₀ = 74 km s⁻¹ kpc⁻¹、r₀ = 3.7 kpc、μ₀ = 1.3 kpc⁻¹（只在 T8 中放开）。ω(z_max, r) 取自式 3，z_max = |ζ(s)|（与 K24 相同）；完全椭圆积分的自变量形式在实现时对照式 3 核对，单元测试检查 z_max → 0 时 ω → ω₀ exp[(r☉ − r)/(2r₀)]，以及 μ₀ z_max = 0.29 时 ω 下降 6–7%（一阶理论给出 −(3/4)μ₀² z_max² ≈ −6.3%）。μ₀ z_max ≥ 1/√2 时轨道不受束缚，似然为零。
- r(s) = √((r☉ − x(s))² + y(s)²)，x 指向银心。
- 平面内基线：经过锚点 (x₀, y₀)（u = 0）、(x₁, y₁)（u = 0.5）、(x₂, y₂)（u = 1）的二次拉格朗日曲线 P(u)，在 u ∈ [−0.2, 1.4] 上取 2000 个点（曲线延伸过第三个锚点，因为 K24 的模型一直延续到天鹅座 X）；s 为从 u = 0 起算的弧长（u < 0 时为负）。一个变体把中间锚点放在其弦长位置（第 4.6 节）。
- Λ(s) = s/(p − γs)（式 6），只在 p − γs > 0 的格点上使用（其他格点不参与最近点搜索）；ζ(s) = −A [1 + ((s − s₀)/δ)²]⁻¹（式 9）；z(s)、v_z(s) 取式 4–5。
- 星团的距离向量 d = (x, y, z, v_z/ω₀) − 最近格点处的模型值，v_z/ω₀ 以 pc 计（ω₀ = 74，T8 中用拟合的 ω₀）；云用 3 维向量 (x, y, z)。似然取式 13（星团）与式 11（云），σ = 47 pc 固定，离群函数 C(d/σ) = (Σₙ tanh((dₙ/σ)²))^½；某个星团只要有一个分量满足 tanh((dₙ/σ)²) > tanh(3)，即 |dₙ|/σ > √3，就是离群点（K24 的规则）。
- 核密度权重：在 s 上的高斯核密度，带宽 100 pc（约为波长度的 3–4%）；每个天体的权重与其 s 处的密度成反比，在各自集合内归一化为天体数。权重用每个天体在 K24 扩展数据表 2 第 (6) 列中位数下的 s 计算一次，抽样时保持不变；固定的权重也保证 T3 的似然是嵌套的。
- 先验：扩展数据表 1，有三处是我们的理解。(i) ω₀t：MCMC 中为 U(−π/2, π/2)；最大似然拟合中按周期处理（第 4.3 节）。(ii) 印出的 ln(μ₀ pc) ~ N(−1.346, 0.25) 给出 μ₀ ≈ 0.26 pc⁻¹，在物理上不合理；我们理解为 ln(μ₀ · kpc) ~ N(ln 1.3, 0.25)，以采用值 1.3 kpc⁻¹ 为中心；注意 −1.346 ≈ ln(ln 1.3) = −1.339，说明印出的值可能多取了一次对数。(iii) ln(ω₀ km⁻¹ s pc) ~ N(−2.4, 0.17) 按印出的使用（ω₀ ≈ 91 km s⁻¹ kpc⁻¹）。

### 4.2 拟合

- T1、T2、T8 的抽样器：emcee，48 个行走者（walker），6000 步，丢弃前 2000 步；报告接受率与自相关时间；若链长短于 50 个自相关时间，以两倍步数重跑；仍然不够时照常使用，并在结果中标记"链偏短"。
- 最大似然拟合：从 20 个起点中取最好的（MCMC 中位数加 19 个先验抽样），先 Nelder–Mead 再 L-BFGS-B，以先验的支撑集为边界；同时报告最大后验（MAP）值。
- 各拟合的设置：第 (3) 列 只用云，B = 1，ω₀t = 0；第 (4) 列 只用星团，B = 1，ω₀t = 0；第 (5) 列 只用星团，B 与 ω₀t 自由；第 (6) 列 云 + 星团，B = 1，ω₀t = 0；第 (7) 列 同 (6)，再放开 ω₀、μ₀、r₀；只用于 T7：第 (6) 列设置下 B = 0.5、ω₀t 自由。
- 顺序：载入检查；第 (3) 列；T5 的已知答案检验（只需要 K24 发表的数值与只用云的后验，此时还没有拟合任何星团；载入检查已经读过星团的 v_z，这与 Wiki 第三部分"在读取数据之前"有出入，但它不做任何拟合）；然后其余拟合。

### 4.3 T3 与 T4

- T3：对其他所有参数求剖面，分别在 B = 0.5 与 B = 1（ω₀t = 0）处；B 自由的最大值中 ω₀t 在 (−π, π] 上按周期处理。为什么 B ≤ 1 而在 B = 1 处仍用 χ²₂：写成第 4.4 节的 2 × 2 矩阵时，波等于缩放乘以旋转（B = 1）加上一个反共形部分，其大小为 (1 − B)、角度 φ + ω₀t 自由；在 B = 1 附近，这部分是围绕 0 的一个自由二维向量，所以 B = 1 是一个正则的二参数族的内点，而不是单边边界（Wiki 第三部分）。χ² 参考分布只是渐近的，所以每个判定还要求由自助法分布本身得到的 p_boot < 0.05。模拟从拟合的零假设模型（B = 0.5 或 B = 1 的拟合）抽取：零假设拟合的每个内点放在离它最近的模型点 (x, y, z, v_z) 上，加上高斯噪声：全部四个分量上 σ = 47 pc（v_z 上即 47 pc × ω₀ ≈ 3.5 km/s），再与该星团的测量误差（`sigmax`、`sigmay`、`sigmaz`、`sigmavz`）按平方和合并；零假设拟合的离群点保留观测值。每个模拟都重新拟合两个模型（3 个起点：生成参数、数据的最佳拟合、一个先验抽样）；B 自由的重新拟合总是也从重新拟合的零假设最优点出发，保证 2ΔlnL ≥ 0，出现负值时截为 0 并计数。每个零假设 N = 100 个模拟。一个报告用的变体改为对零假设拟合的残差向量重抽样来抽取噪声。
- T4：模拟用同样的星团（按编号取 B = 0.5 拟合的内点；不重新应用离群规则）。驻波模拟按 T3 的方式从 B = 0.5 拟合抽取；功效模拟从 B = 1 拟合抽取（作为报告，也从 B 自由拟合抽取）。所有模拟都在 B = 0.5 拟合的曲线上重新求最近点（s_k，从而 ω_k），不重新拟合，与对数据的做法相同。每个功效模拟的 R 与同样的 N₄ 个驻波模拟比较，其 p 也用 p_boot = (1 + k)/(1 + N₄)。φ_k = arctan(z_k ω_k / v_z,k) 中 z 以 pc、ω 以 km s⁻¹ pc⁻¹、v_z 以 km/s 计。每种 N₄ = 1000 个模拟；一个报告用的变体改用残差重抽样。

### 4.4 T5

- 基线、Λ(s) 与 s 取自第 (3) 列只用云的后验；每个星团的 s 为它在 x–y 平面上向基线的投影；最近点落在格点端点的星团剔除并计数。
- 星团集合（只用位置）：某个星团在其最近点处相对只用云的模型的 x、y、z 残差都小于 √3 × 47 pc 时保留；变体用 3σ 或全部 125 个（第 4.6 节）。
- 每个分量取 A·ζ̃(s)·sin(2πkΛ(s) + ψ)，A ≥ 0、k ∈ [0.3, 3]；ζ̃ 为只用云的包络形状除以其峰值；v_z 除以 ω(s)，ω(s) 以只用云的包络作为 z_max。用加权最小二乘，权重为第 4.1 节的核密度权重（在这些 s 上重新计算），误差为测量误差与 47 pc 弥散按平方和合并。k 先在 0.3 到 3、步长 0.01 的格点上搜索，再细化；落在边界上的 k 予以报告。k 分开的拟合：k_z 与 k_vz 分开；共用 k 的拟合：只有一个 k。

### 4.5 T7

### 4.7 开销与顺序

主运行：5 次 MCMC 拟合加 T7 的拟合；约 10 次最大似然拟合；T3：2 个零假设 × 100 个模拟 × 2 次重新拟合；T4：3 × 1000 次模拟计算（不重新拟合）；T5：1000 次最小二乘自助法拟合，以及已知答案检验（60 个模拟 × 各 1000 次重抽样）。T6：15 个变体（9 个单项改变，6 次去掉星表分开计），每个约 3 次最大似然拟合，加上按上述次数的 T4 与 T5；变体 1 与 2 另需 2 × 100 个带重新拟合的 T3 模拟，变体 10 另需一次只用云的 MCMC。粗略估计在单核上需要 4–10 小时；正式运行之前用一次短的计时运行测量。上述次数是下限，不会减少：T3 每个零假设 100 个模拟，T4 1000 个模拟，T5 每次注入 20 个模拟，自助法 1000 次重抽样。若预计时间超过 10 小时，运行做断点保存，在之后的空闲时段继续，次数不变。正式运行要等到没有其他研究在运行时进行。结果文件（`results/`）：`t1_t2.json`、`t3.json`、`t4.json`、`t5.json`、`t6.json`、`t7.json`、`t8.json` 与 `summary.json`，每个都小于 1 MB（链经过稀疏或汇总）。

### 4.9 拟合之前的修订（2026-11-21）

以下各点是在实现 `run.py` 时、对数据拟合任何模型之前确定的。它们补足第 2–4.8 节留下的选择，没有改动上面任何规则或阈值。每一点都在对数据做任何拟合之前确定。

1. **载入检查的权重**（第 3 节）。加权平均使用第 4.1 节固定的核权重（kernel weights）。逆方差权重（inverse-variance weights）无法定义，因为有三个星团的 `sigmavz` = 0.0。检查载入时得到的三个平均值：核加权 −2.18 km/s（判定所用的值）、不加权 −1.44 km/s、带 0.05 km/s 下限的逆方差加权 +1.19 km/s；三者都通过。在对数据做任何拟合之前确定。
2. **变体 1 的似然**（第 4.6 节）。每个分量的项改为 c = 3·tanh(x²/3)，于是残差小时似然为高斯形式，离群边界为 |x| > 3。在对数据做任何拟合之前确定。
3. **T3 重新拟合的起点**（第 4.3 节）。对零假设模型的重新拟合，"生成参数"与"数据的最佳拟合"是同一点，所以只用两个不同的起点（该点与一次先验抽样）。对数据的 B 自由拟合除了 20 个起点，还从两个零假设模型的最优点出发，以保证 2ΔlnL ≥ 0。在对数据做任何拟合之前确定。
4. **MCMC 拟合的次数**（第 4.2、4.7 节）。完整运行共 8 次：主运行 7 次，即第 (3)、(4)、(5)、(6) 列，以及第 (7) 列三次（K24 的先验、宽先验、除数固定为 74），另加变体 10 的一次（第 (3) 列，用弦长 u₁）。T7 的拟合是最大似然拟合。在对数据做任何拟合之前确定。
5. **链长规则**（第 4.2 节）。用烧入（burn-in）之后的长度与最大自相关时间（autocorrelation time）的 50 倍比较。重跑时步数与烧入长度都加倍。在对数据做任何拟合之前确定。
6. **T8 的除数 74 变体**（第 2 节 T8）。在 K24 的先验下运行。在对数据做任何拟合之前确定。
7. **已知答案检验的放置**（第 4.4 节）。每个入选星团放在注入模型上离其三维位置 (x, y, z) 最近的点，不使用任何速度。在对数据做任何拟合之前确定。
8. **T5 的自助法**（第 4.4 节）。每次重抽样都从全部输入星团中抽取（对数据是全部 125 个；对已知答案模拟是该模拟的星团集），并重新施加网格端点剔除与位置截断。"网格端点"指第一个或最后一个有效格点（p − γs > 0）。在对数据做任何拟合之前确定。
9. **变体中的核权重**（第 4.1、4.6 节）。对每个变体的数据，在 K24 第 (6) 列中位数下重新计算，包括子集、变体 6 平移后的 v_z 以及变体 10 的弦长曲线。在对数据做任何拟合之前确定。
10. **点估计。** T7 (a) 使用第 (6) 列的最大似然拟合。Θ₂ 由各版本自己的内点（inlier）计算。T7 使用全部 79 个云。T1 的内点集合来自后验中位数参数。B = 0.5 的最大似然拟合从第 (5) 列 MCMC 中位数出发，并把 B 设为 0.5。在对数据做任何拟合之前确定。
11. **式 13 的常数项。** 3 ln(2πσ²) 按原文保留，尽管距离矢量有四个分量。σ 固定时它在所有比较中抵消。在对数据做任何拟合之前确定。
12. **T3 的残差重抽样变体**（第 4.3 节）。保留，并对 2 个零假设 × 100 次模拟完整地重新拟合。它额外需要约 3 小时，第 4.7 节没有计入。在对数据做任何拟合之前确定。

14. **开销估计**（第 4.7 节）。在真实规模的合成数据上实测，一次似然计算约 1.2 ms（星团）或 1.9 ms（星团加云）。整个运行的预计上限约为单核 16 小时：T3 模拟 6.2 h，T6 8.6 h，MCMC 0.9 h。正如第 4.7 节已经写明，运行因此在 10 小时处暂停，在之后的空闲时段继续；各次数不变。在对数据做任何拟合之前确定。
15. **b̂ 的已知性质。** 在合成的已知答案模拟中，b̂ 偏低：B = 0.84 时均值为 0.565（目标 0.68），B = 1 时为 0.785。因此已知答案检验可能不通过，从而使 b̂ 的标签为"未定"。规则不变。在对数据做任何拟合之前发现并记录。

*A 部分，R-CONV：什么约定能复现第 (3) 列？* 十六种约定，即三个因素的全部组合（每个因素的第一个选项就是正式运行的；编号为 基线·4 + σ·2 + 权重，选项按列出的顺序编为 0, 1, …）：
- **基线（四个选项）。** L：通过 u = 0、0.5、1 处锚点的参数化拉格朗日曲线 P(u)（第 4.1 节）。C：同上，但中间锚点放在弦长位置（变体 10）。Y：y 作为 x 的二次函数通过三个锚点（要求 x₀ < x₁ < x₂ 或 x₀ > x₁ > x₂；否则似然为零）。X：x 作为 y 的二次函数通过三个锚点（对 y 的同样单调条件），因为"a quadratic function in x and y"在措辞上是对称的，而且波在 y 方向的跨度大于 x 方向。每个选项中曲线都从锚点 0 之前锚点跨度的 0.2 延伸到锚点 2 之后的 0.4（正式运行的范围；分别以参数 u、x 或 y 计），s 是从锚点 0 起在 x–y 平面内的弧长，网格 2,000 个点。保留正式运行的范围，是因为在 K24 的中位数处 79 个云中只有 1 个的 s < 0，从锚点 0 开始曲线几乎没有改变。

*约定的选择（现在固定）。* (i) 若没有一种约定的计数 ≥ 3，A 部分的结论为"在任何候选约定下都未复现"，到此为止。(ii) 否则，在计数 ≥ 3 且宽度比在 [2/3, 3/2] 之内的约定中选计数最大的；(iii) 若计数 ≥ 3 的约定中没有一个宽度比在该范围内，就在它们之中选计数最大的（这时标签为"部分复现"，并写明原因）。平局时先选与正式运行（L、F、W）不同的因素个数最少的，再按编号。标签（每个都写明"这 16 种候选约定中最好的，事后"）：
- **"第 (3) 列在 <约定> 下复现"**：计数 ≥ 5 且宽度比在 [2/3, 3/2] 之内；

**这意味着什么。** 用 K24 自己的数据与模型，我们的拟合得到与他们相同的 B ≈ 0.84，主分析中似然比偏向行波型而不是驻波。但这一偏好依赖少数星团：去掉猎户座区域（58 个星团）或去掉核权重，偏好就消失（2ΔlnL 1.2 与 5.4）；去掉 v_z 误差较大的星团也是如此（2.3）；去掉四个来源星表中的任何一个，2ΔlnL 仍有 12–15，但降到排除阈值以下（校准 p 0.06–0.10）。相位离散检验（T4）功效不足，无法判定；不依赖模型的 b̂（T5）也无法解读，因为已知答案检查在 B = 1 未通过。T8 在 ω₀ 自由时的判读撤回（第 6 节第 1 点）；除数固定时 ω₀ = 71 km s⁻¹ kpc⁻¹，接近 K24 的 67.7。CO 速度若说偏向什么，B = 1 模型拟合得比 v_z = 0 还差。我们对第 (4) 列的复现与 K24 的 6 个形状参数中的 3 个相符；波长 p 短约 330 pc（1.7σ），相位 φ 相差 0.37 rad，所以其余检验针对的是我们的实现。

## 7. 开放问题

- 什么约定能复现 K24 只用云的拟合（第 (3) 列）？候选：曲线从 u = 0 而不是 −0.2 开始；按 K24 的描述由 d² 的离散估计 σ；在每个参数向量处重算核权重。然后重跑 T1，并在我们自己的拟合上注入做 T5 已知答案检查，使注入与分析共用一条曲线（审稿，第 6 节第 2、3、11 点）。**由 R-CONV 回答（2026-11-22，T-056，第 5.1 节）：16 种约定都不能**（基线 L、C、Y、X；σ 固定或由 d² 的离散得到；权重固定或重算）复现第 (3) 列；它们都给出同样两个在内、四个在外。仍未解决：s 的起点与 Λ(s) 的形式、太阳的 z 偏移，以及我们的 79 个云及其位置是否与 K24 的相同（在 K24 中位数处的逐云诊断，T-061）；在所有约定中还都固定了式 11 的 ln(2πσ²) 常数（只在 P 下有影响）与中心接近 K24 结果的先验（这会削弱我们的偏移）。
- 当 v_z 的除数被拟合时，T8 需要一个对 ω₀ 不病态的似然（例如不截断的速度项，或除数固定、ω₀ 只通过频率进入）；按预注册的形式它没有信息量（第 6 节第 1 点）。**由 T8-P 回答（2026-11-22，T-056，第 5.1 节）：** 除数固定时，数据对 ln ω₀ 的约束与 K24 的先验一样紧，偏好 59 km s⁻¹ kpc⁻¹；标签为"prior-driven"（半宽 0.172，上限 0.085），K24 的 67.7 介于先验与数据之间。
