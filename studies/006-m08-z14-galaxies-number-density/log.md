- 独立审稿（referee）：没有代码错误。主要意见：z ≈ 8 光度函数的不确定性没有传播，而它起主导作用；用探索脚本 `explore/lf_uncertainty.py` 复核：φ*、M*、α 任一参数按 1σ 移动都会使 R2 与 R3 的判定翻转；去掉 0.3 mag 的 z ≈ 8 尘埃消光就使 R3 变为"不同"。结论收窄为：恒定 SFE 模型预言的数目多于 N26 的基准（2–37 倍，大多 > 3 倍），所需 σ_UV 在 1–2 mag 左右，与 N26 的 1.5–2 mag 是否重叠没有稳定的判定。Lean 加入第四个缺口 `gap_bin`（星等与红移箱是围绕两个探测选的）。补上按丰度加权的"箱中晕位于校准范围内"的比例（1.000）。登记后续任务 T-025（用带误差的分箱数据校准并传播后验）。
- 首次运行（12 秒，不取数据）。结果见 README 第 5 节：
  - R1：log φ = −5.364（+0.365/−0.451），体积 460,463 Mpc³（与 N26 差 −0.5%），复现；泊松尾概率在比值 182 与 100 时为 59.9 与 197.4 ppm，Lean 的 `mod_poisson` 界成立。
  - R2：恒定恒星形成效率（SFE）模型的基准组合预言为 N26 基准的 9.4 倍，判定"更高"；72 个变体都可评估，61 个"更高"、11 个"同一量级"，包络 2.5–37 倍，判定依赖校准。
  - R3：所需紫外弥散中心值 1.38 mag，泊松界 1.15–1.57 mag，与 N26 的 1.5–2 mag 重叠，判定"一致"；变体中 38 个一致、34 个不同，依赖校准；中心值包络 1.07–1.60 mag。
  - 拟合的中位数关系不单调（γ = 1.98 > 1.1），z = 14.5 时目标星等箱中的晕有一部分位于校准范围之外（峰值以上的下降分支），这部分晕极少。
  - 预注册的 z = 0 质量分数检查比较的是同一个积分的两种写法，没有信息量，在 README 中如实说明。
