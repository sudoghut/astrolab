Galaxies at z ≈ 14: how many, and how much scatter would a constant-efficiency model need?z ≈ 14 的星系：有多少？恒定效率模型需要多大的弥散？

Naidu et al. 2026 (arXiv:2505.11263) infer the z = 14–15 number density from two confirmed galaxies and compare it with a pre-JWST LF they construct. This study recomputes the density, builds an independent constant star-formation-efficiency halo model calibrated on the pre-JWST z ≈ 8 LF, and asks what UV scatter it needs. Criteria are pre-registered in the README (sections 1–4); the argument is decomposed in the wiki article.Naidu 等 2026（arXiv:2505.11263）由两个确认的星系推出 z = 14–15 的数密度，并与他们构造的 JWST 之前的光度函数比较。本研究复算数密度，构造一个独立的、以 JWST 之前 z ≈ 8 光度函数校准的恒定恒星形成效率晕模型，并问它需要多大的紫外弥散。判据预注册在 README 第 1–4 节；论证拆解见 Wiki 文章。

The last row (R3-POST2, a second addendum) samples σ_cal on [0.3, 1.2] mag, uses Poisson likelihoods for the two brightest blank-field bins and allows γ < 0; the data barely constrain σ_cal, so its probabilities are conditional on that prior range.预注册的敏感度检验（README 第 2 节补充）：用带误差的分箱 z ~ 8 光度函数校准模型，传播 500 个后验样本；只有当判定的概率减去两倍蒙特卡洛标准误差不小于 0.95 时才算"稳健"。以基准模型成分为条件（Sheth–Tormen、"dpl" 外推、不改正尘埃）。最后一行（R3-POST2，第二次补充）在 [0.3, 1.2] mag 上对 σ_cal 采样，最亮两个空白天区分箱用泊松似然，并允许 γ < 0；数据几乎约束不了 σ_cal，所以这一行的概率以该先验范围为条件。
