R1-ERR · Does R1-SEL-FIT's label depend on the age-error scale? (T-054)R1-ERR · R1-SEL-FIT 的标签是否取决于年龄误差的尺度？（T-054）

Pre-registered in README 2.7. Power mocks of the three metal-poor bins draw observed ages with true errors f × e_Age (f = 1.2, 1.5, 2.0, 2.81) and are fitted with the quoted errors (f = 1) exactly as in R1-SEL-FIT. A bin is "explainable at f" if at least 3 of 50 mocks, under at least one mechanism, have a valley at least as shallow as the data's (n_reach). The label (S15 term E) is "sensitive at f = Y" if two or more bins are explainable at some f, else "robust up to f = X". It qualifies R1-SEL-FIT's label; it is not a verdict on XR22's claim, and it does not say whether such errors are plausible.预注册见 README 2.7。三个贫金属箱的功效模拟用 f × e_Age 的真实误差抽取观测年龄（f = 1.2、1.5、2.0、2.81），再用给出的误差（f = 1）完全按 R1-SEL-FIT 的方式拟合。若在至少一种机制下 50 次模拟中至少 3 次有谷且谷不比数据的浅（n_reach），该箱"在 f 处可解释"。标签（S15 项 E）：若某个 f 下有两个或更多箱可解释，则为"在 f = Y 处敏感"，否则为"直到 f = X 稳健"。它是 R1-SEL-FIT 标签的限定语，不是对 XR22 结论的判决，也不说明这样的误差是否合理。

R1-ERRMM · fitting with too large an error scale, and a bootstrap of the data's dip (T-064)R1-ERRMM · 用过大的误差尺度拟合，以及数据下凹的自助法（T-064）

Pre-registered in README 2.9. Part A: the skew-normal and split-normal null mocks of the three metal-poor bins are drawn with true errors g × e_Age (g = 1.0 and 1.5) and fitted with F = 2.81; their q_s give a threshold d*_mm per bin, and R1-ERRCAL's 2.81 verdict is recomputed with it (R1-ERRCAL's power sets and data fits are reused). It qualifies R1-ERRCAL's 2.81 verdicts; it is not a verdict on XR22's claim.预注册见 README 2.9。A 部分：三个贫金属箱的偏斜正态与分裂正态零假设模拟以 g × e_Age 的真实误差生成（g = 1.0 与 1.5），再以 F = 2.81 拟合；它们的 q_s 给出每箱的阈值 d*_mm，并以此重算 R1-ERRCAL 在 2.81 下的判决（沿用 R1-ERRCAL 的功效组与数据拟合）。B 部分：对每箱的恒星做 100 次重抽样，按模拟流程以 2.81 拟合；判决与 R1-ERRCAL 相同的重抽样比例不低于 0.80 时为"稳定"。它是 R1-ERRCAL 在 2.81 下判决的限定语，不是对 XR22 结论的判决。

Bootstrap of the data at 2.81 (part B)2.81 下数据的自助法（B 部分）

Post hoc (referee, README 5.5): every data fit at 2.81 and 96–100% of the resamples have a component at the width floor σ = 0.1 Gyr, which the smooth nulls reach in only 0–32% of mocks. The nulls have no sharp old edge, so "robust to an f mismatch" holds for smooth one-peaked latent distributions only; the bootstrap is anchored at the data's fit, so its spread is a lower bound. A wider-floor refit and a sharp-edged null are registered (T-067).事后（审稿，README 5.5）：2.81 下的每个数据拟合与 96–100% 的重抽样都有成分落在宽度下限 σ = 0.1 Gyr，而平滑的零假设只有 0–32% 的模拟如此。零假设没有陡峭的老边缘，所以"对 f 不匹配稳健"只对平滑的单峰潜在分布成立；自助法锚定在数据的拟合上，所以其离散是下限。加宽下限的重拟合与陡峭边缘的零假设已登记（T-067）。
