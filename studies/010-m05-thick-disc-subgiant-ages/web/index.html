R1 · Is there an 8 Gyr gap at fixed [Fe/H]?R1 · 在固定 [Fe/H] 下有 8 Gyr 的空隙吗？

Deconvolved latent age density of each [Fe/H] bin (Gaussian mixture, K by BIC). The marked valley is the deepest one in 5–11 Gyr; d is its depth relative to the lower neighbouring peak (d = 1: no valley). A bin is "almost disjoint" if d < d*, the threshold calibrated on unimodal null mocks; it counts only if the bin is resolvable (power ≥ 0.8 on mocks built from XR22's own sequence).每个 [Fe/H] 箱去卷积后的潜在年龄密度（高斯混合，K 由 BIC 选择）。标出的谷是 5–11 Gyr 内最深的一个；d 是谷深相对于较低一侧峰的比值（d = 1 表示无谷）。d < d*（由单峰零模型模拟标定的阈值）的箱算"几乎不相交"；只有可分辨的箱（在按 XR22 序列构造的模拟上检出率 ≥ 0.8）才计入。
