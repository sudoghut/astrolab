### 正式运行与结果（T-019，计划 019 环节 5）

- 正式运行第一次（11-15 夜）在模拟阶段被 Claude Code 因系统内存不足终止；经用户同意清空 `results/` 后重跑，耗时 3.53 h。模拟预算按预注册规则投影：每组 50 次需 4.29 h（> 4 h），因此每组改为 30 次（R1 的 q_s 取第 2 小）。投影偏大的原因是同时在本机运行了研究 002 的正式运行（我们的调度所致）；按写好的规则执行，不另作改动。
- **R1（8 Gyr 分开）：无法判定（undetermined），S15 与 Full 一致（稳健）。** S15 只有两个箱可分辨（resolvable）：[−0.7, −0.5) 与 [−0.5, −0.3)，谷深 d = 0.29、0.45，都高于 d* = 0.25，没有"几乎不相交"的箱；富金属的箱没有谷，功效（power）为 0。所有零假设（null）模拟都没有低于 0.25 的谷，d* 停在上限 0.25。
- **R2（13 Gyr 均值）：复现。** 观测年龄的高斯拟合 μ = 12.93 ± 0.06 Gyr（σ = 2.40，论文 1.81），n = 1891；去卷积（deconvolved）的潜在均值较低：12.19（S15）、12.59（Full）。年龄标尺包络约 ±0.7–1.1 Gyr，整体重新分析可年轻 1.7 Gyr，而距宇宙年龄只有 0.87 Gyr 的余量。
- **R3/R4（老盘序列）：无法判定。** 样本 A 的拟合 σ = 2.67 Gyr、跨度 6.00 Gyr，但两种误差机制下的恢复检验（recovery）σ 偏差 +0.28 与 +0.25 Gyr，超出 0.1 的容差，按预注册规则两者都"无法判定"；原因见下面的独立审稿：S15 选择项在两种误差机制下都设定错误。
- **内禀离散（intrinsic scatter）：无法判定。** 样本 B 的 σ_int = 0.79 ± 0.02 Gyr（论文 0.82），但模拟偏差 +0.13 到 +0.18 Gyr，超过 0.1。
- 描述性：R5 交叉比例 23.6%（晚期中老于 8 Gyr）与 19.4%（早期中年轻于 8 Gyr）；R6 高 J_φ 早期星观测年龄峰在 11.1 Gyr；R7 的潜在年龄分布很宽（f = 1 时 95% 宽度 12.6–13.0 Gyr），远不如 Miglio 等人的 1.52 Gyr 紧致，但示踪体与去卷积不同，且我们的宽度因恢复偏差而偏大。
- **独立审稿（referee）**（只看预注册、代码、结果与 Lean 对照表；作了离线合成检验）的主要意见及处理（事后，post hoc；预注册判定不变）：(1) M0 的 S15 选择项在 e = r·τ 与 e = r·A 两种机制下都设定错误——r 与 τ 无关时截断与 τ 无关（r·A 下只是对 r 的截断），这才是 R3/R4 与内禀离散无法判定、以及 S15 与 Full 不同的原因；README 2.0 中"压缩编码了随观测年龄变化的误差"的理由也因此不对（在第 5 节更正）。(2) R1 功效模型（power model）中老成分 10% 的下限永远通不过 10% 的两侧质量规则，[−0.1, 0.1) 箱按构造无法分辨。(3) 实质上：可分辨的箱都不是"几乎不相交"（d = 0.29–0.58），R3 的跨度在样本 A 的各变体中都在 5.7–6.2 Gyr，R4 的 σ_sel 在各变体中都是 2.4–2.7 Gyr，约为 XR22 的三倍。(4) Lean：`mod_bin` 把 XR22 的"presumably the oldest thick disk stars"编码成断言并标为论文明说，强于引文，改为 `gap_bin`（GAP，我们补上的），论证现有三个缺口。重新检验登记为 T-031。审稿表见 README 第 6 节。
