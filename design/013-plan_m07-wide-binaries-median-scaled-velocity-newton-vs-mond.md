## 1. 目标

按论文立项流程（`paper-study` 技能，计划 007）把 M7 立为研究：

- 用 Gaia DR3 的服务器端自连接（self-join）重建一个与 Cookson et al. 2026（arXiv:2602.24035，下称 C26）同样标准的干净宽双星（WB, wide binary）样本，不下载 El-Badry 等 2021 的 1.8 GB 星表（AGENTS.md 第 1.5 节）；
- 复现 C26 的检验：缩放相对速度（scaled relative velocity）ṽ ≡ v_sky / √(GM/r_sky) 的中位数在 r_sky/r_M（r_M 为 MOND 半径（MOND radius））各箱中的走势，比较"平的牛顿线"与"MOND 台阶（式 7）"，两者的归一化都自由；
- 检验 C26 的结论"在最干净的样本中没有 MOND 的证据"（牛顿的似然约为 MOND 的 1500 倍），并描述性地探索 C26 第 7 节所说的、能"制造 MOND 假象"的选择（不做球面投影修正、不做赫罗图（HR, Hertzsprung–Russell）切割、更远的距离、更严的视差信噪比）。

## 2. 已知的数字与方法（环节 2 读全文后核实）

- C26 样本：母星表 C25（视差相对误差 ≤ 2.5%，即 parallax_over_error > 40），主分析 ≤ 130 pc；r_sky ≲ 30 kAU（§3.1.3）；RUWE < 1.25；100 kAU 以内的三体与多重系统去群（去群的输入包括没有视向速度或 BP/RP 的暗星，§3.2.2）；赫罗图平行四边形 0.5 < BP−RP < 3.5、高 0.8 mag、斜率 3.3、4 < M_G < 14；ΔRV < 10 km/s（因此两颗星都要有视向速度（RV, radial velocity））；σ(ṽ) < 0.1；ṽ ≤ 2.5（变体 2、1.5）；每一项逐星切割两颗星都要通过；质量用 FLAME（约 19% 有），其余用式 12：M⋆ = 10^{0.0725(M_G,⊙ − M_G)}（M_G,⊙ 取自 Willmer 2018，约 4.67，待核），M⋆ < 0.7 时加 0.05 M⊙（待核）；两星放在逆方差加权的平均视差距离上；做球面投影修正（perspective correction，用到系统视向速度）。
- ipd_frac_multi_peak = 0 **不是主切割**：只用于表 3 中 N = 1216、ṽ ≤ 1.5 的一行与 150 pc 的检验。
- 常数：a0 = 1.2 × 10⁻¹⁰ m/s²；r_M = √(GM/a0)；外场 g_e = 1.785 a0（对应 g_N,e = 1.184 a0）。
- 分箱：C26 表 2 只给出各箱 r_sky/r_M 的中位数（0.073、0.153、0.348、0.744、1.419、3.079），不给边界；逐箱的 ṽ 中位数只在图 8 中（牛顿线 0.489）。环节 2 数字化图 8（带误差），环节 3 在取任何速度之前写定我们的分箱边界（由上述中位数重建的对数等距边界，相邻中位数约相差 2.1 倍，用只含 r_sky/r_M 的计数核对），并明确写出最外两条边界：最低的 r_sky/r_M 与由 r_sky ≤ 30 kAU 决定的上边界。
- 中位数误差：C26 用 1.4826·MAD/√N（即 σ/√N）；中位数的渐近标准误约为 1.2533σ/√N，所以 C26 的误差约小 20%，Δχ² 约大 1.57 倍（大样本近似下的诊断，前提是两者的离散定义相同；环节 2 读全文时核对 C26 的估计量）（C26 表 3：χ²_N = 2.48/1.46，χ²_M = 15.10/16.09，Δχ² 约 12.6–14.6，除以 1.57 后约 8–9.3，正好落在判据附近）。
- C26 统计量：各 r_sky/r_M 箱中 ṽ 的中位数（C26 的误差为 1.4826·MAD/√N）；牛顿为平线，MOND 为式 7 的台阶（外场 g_N,e = 1.184 a0，r ≈ r_sky√(3/2)）；χ² 比较，似然比 exp(Δχ²/2)。我们的定义（主要误差、归一化）见第 4 节 R2。
- C26 结果（表 3）：548 倍（N = 1421，ṽ ≤ 2.5）、883 倍（ṽ ≤ 1.5）、1501 倍（N = 1216，ṽ ≤ 1.5 且 ipd = 0）。
- 效应大小：MOND 预期中位数 ṽ 在 r_sky ≳ r_M 处升高约 20%（例如 0.5 → 0.6）；N ≈ 1200–1400 分 6 箱，每箱中位数误差约 0.02–0.03。
- C26 的其他数字（用作 R3 的定量参照）：150 pc 时 MOND 受偏好约 12 倍；150 pc 加 ipd = 0 时牛顿受偏好约 88 倍；不做投影修正会使 r_M 附近的中位数 ṽ 升高约 0.15。
- 待核（环节 2）：M_G,⊙ 与低质量加 0.05 M⊙ 的规则、HR 平行四边形的精确顶点、投影修正公式、σ(ṽ) 的误差传播（需要视差与自行的相关系数列）、去群的具体算法（C24 第 2.3 节；HTML 版不可用，读 PDF 或期刊版）、母星表的初始配对条件（角距离、视差一致性、v_sky 上限）、C26 是否让 MOND 的归一化也自由、C24 与 C26 的期刊卷页。

## 3. 数据与大小（AGENTS.md 第一条）

- 只用 Gaia 档案（gea.esac.esa.int）的服务器端 ADQL，分两类查询：
  1. **候选对**：在 parallax > 6.667 mas（150 pc）、parallax_over_error > 40 的母样本上做自连接，配对条件在服务器端算好（投影距离 ≤ 100 kAU、视差一致、自行差对应的 v_sky 上限），每颗星只取需要的列：位置、视差、自行及其误差与相关系数（ra_dec_corr、ra_parallax_corr、ra_pmra_corr、ra_pmdec_corr、dec_parallax_corr、dec_pmra_corr、dec_pmdec_corr、parallax_pmra_corr、parallax_pmdec_corr、pmra_pmdec_corr）、G/BP/RP、RUWE、ipd_frac_multi_peak、视向速度及其误差，以及经服务器端连接 astrophysical_parameters 得到的 FLAME 质量。
  2. **去群用的宽松邻居计数（逐星计数）**：`astrolab.fetch.tap` 不能上传表，逐对计数需要三重连接，未经检验且可能超时，所以改为逐星计数：对母样本中的每颗星（parallax > 6.667、parallax_over_error > 40），在服务器端数出在它的距离上投影 100 kAU 以内、视差一致的宽松邻居（任何五参数星，不限 RUWE、颜色、视向速度），`GROUP BY a.source_id`，只返回 source_id 与计数 n（不含星本身）。在本地，只有两颗成员星的邻居计数都等于 1、且这唯一的邻居就是伴星时才保留这一对（查询在 n = 1 时同时返回该邻居的 source_id，例如 MIN(b.source_id)；本地还核对伴星本身满足同样的邻居规则）。只返回 n ≥ 1 的星（n = 0 的星不可能是成员）。邻居的视差规则须防止误差很大的暗星"匹配一切"而过度去群：除 kσ 一致外，还要求邻居的视差误差上限；邻居样本的视差下限不能沿用 6.667（否则 150 pc 附近视差有噪声的真伴星会被漏掉，去群不足），改用 parallax + kσ > 6.667 或略低于 6.667 的固定下限；具体规则在环节 2 从 C24 第 2.3 节写定并写入 README 第 3 节。逐星输出可能超过 50,000 行，查询写明 max_rows（不超过硬上限）。环节 2 在 11-18 之前做计数（母样本的 tap_count）与单条带计时试验，记下行数与秒数，写入 `log.md` 与 README 第 3 节的数据表。
- 分条带：只把星 a 限制在赤经条带内（24 条带，不重叠），星 b 在全天范围内匹配，因而不需要重叠；每对按 source_id_a < source_id_b 规范排序后去重（同一对可能从两颗星各出现一次）；赤经 0/360 的接缝与两极（|δ| > 80°）由星 b 不受条带限制自动处理，并在不联网测试中核对去重逻辑。
- 可行性试验（2026-11-14，130 pc、parallax_over_error > 40、RUWE < 1.25、50 kAU、视差差 < 10%）：15° 条带得到 2424 个候选对，用时 42 s；全天约 6 万行，约 10 MB。去群需要 100 kAU 与较宽的母样本，环节 3 先在服务器端计数再写入 README 第 3 节。
- 预算：全部输入估计 10–40 MB，低于 200 MB；单次查询远低于 50 MB 与行数上限。这只是估计：环节 2 对每一类查询先在服务器端计数（经 `astrolab.fetch`），写下预期行数与字节数后才定日程；放不下时缩小或拆分查询，仍放不下就停下来请用户决定。
- **时间约束**：Gaia 数据库 2026-11-25 至 12-02 下线；取数必须在 11-24 之前完成并缓存（缓存在 `%LOCALAPPDATA%`，结果只存小文件）。**取数分两步，以保证盲化**：(a) 预注册提交之前，只取不含速度的列（位置、视差及其误差、测光、RUWE、ipd_frac_multi_peak、是否有视向速度的标志、FLAME 质量）与逐星的邻居计数，配对条件中的自行一致性在服务器端判断但不返回自行；(b) 自行、视向速度及其误差与相关系数只在预注册提交（带日期）之后取。若 11-24 之前完不成预注册，(b) 仍在 11-24 之前取，但研究明确标为"未盲化（unblinded）"，不称为预注册的检验。预注册之前只允许不用速度的计数（r_sky/r_M、质量切割）；σ(ṽ) 与 N(ṽ ≤ 2.5) 都在预注册之后计算。缓存约 10–40 MB，远低于 2 GB 的 LRU 上限；收尾之前不清缓存（`cache clear` 禁用，写入日志）。后备：环节 3 写明一个 DR3 的 TAP 镜像（例如 VizieR 的 I/355），核对它是否有相关系数列与 FLAME 质量（I/355/paramp），注明列名差异、跨服务缓存不影响来源记录，并说明在 VizieR 上做邻居计数可能更慢。

## 4. 设计要点与判据方向（预注册写在研究 README 第 2 节）

- **R1（复现样本与中位数曲线）**：同样的切割下，样本数与 C26 的 N（1421、1216）在 ±20% 以内，各箱中位数 ṽ 与数字化的 C26 图 8 在各自误差的 2 倍以内，总体中位数与 0.489 比较。样本数超出 ±20% 时，R2 照算，但标为"样本不同，不是复现"，并做逐项打开切割的诊断链。
- **R2（检验 C26 的结论）**：Δχ² = χ²_MOND − χ²_Newton（两个模型各有一个自由的归一化，不嵌套，所以 exp(Δχ²/2) 是相对似然（relative likelihood），不是威尔克斯检验，也不是后验几率）。去群之后每颗星只属于一对，各箱的双星与恒星都互不重叠；**主要误差**为对双星做自助法（bootstrap）整体重抽样（每次重抽全部双星再分箱），得到六个箱中位数的协方差矩阵，并在拟合中使用（不假设各箱独立）；C26 的 1.4826·MAD/√N 只作复现栏。判定用主要误差（事先写定）：相对似然 exp(Δχ²/2) ≥ 100 → "牛顿的相对似然高（与 C26 的结论一致）"；1/100 < 相对似然 < 100 → "不能区分"；≤ 1/100 → "MOND 的相对似然高（与 C26 矛盾）"。100 这一门槛是约定，不作贝叶斯证据解释。另报告似然比与 C26 的 548/883/1501 的比较（描述）。
- **R3（敏感度，只作描述）**：逐项放松 C26 第 7 节列出的选择（不做投影修正、不做 HR 切割、扩展到 150 与 200 pc、改用视差信噪比 > 100 的母星表、ipd = 0、不去群），所有变体一起报告，与 C26 的定量说法（150 pc 时 MOND 约 12 倍、加 ipd = 0 后牛顿约 88 倍、不做投影修正中位数升高约 0.15）对照；任何变体都不得升为主要结果。
- **R4（可选，描述）**：B24 的距离与切割（250 pc、G < 17 等）下的中位数曲线，作为与 B24 的定性对照；不复现 B24 的完整 MCMC 模型。
- 盲化（blinding）：环节 3 预注册之前不计算任何 ṽ 或中位数；可行性试验只计配对数（只下载了一个计数，没有自行数据）。C26 的曲线是公开的，所以盲化保护的是我们的分析选择，而不是我们对答案的无知。
- **Lean 拆解的方向**（按 AGENTS.md：本质上是观测结论的论断必须拆成计数与统计模型，数值前提绑定到 `run.py` 的结果，不在 Lean 中"推出"观测结果）：把"牛顿受偏好约 1500 倍"拆成计数与统计模型：观测到的中位数平坦（OBS/NUM）；MOND 预期 r_M 以外升高约 20%（MOD）；切割去掉污染而不使 ṽ 产生偏差（可能的 GAP）；误差模型（STAT；中位数误差的问题可能是真正的缺口）；"130 pc 而不是 150 pc 才是干净样本"（可能的 GAP，因为 150 pc 会翻转符号）。"没有 MOND 的证据"与"牛顿的似然高约 1500 倍"分开处理。
