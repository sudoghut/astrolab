## 1. 目标

按论文立项流程（`paper-study` 技能，计划 007）把 M7 立为研究：

- 用 Gaia DR3 的服务器端自连接（self-join）重建一个与 Cookson et al. 2026（arXiv:2602.24035，下称 C26）同样标准的干净宽双星（WB, wide binary）样本，不下载 El-Badry 等 2021 的 1.8 GB 星表（AGENTS.md 第 1.5 节）；
- 复现 C26 的检验：缩放相对速度（scaled relative velocity）ṽ ≡ v_sky / √(GM/r_sky) 的中位数在 r_sky/r_M（r_M 为 MOND 半径（MOND radius））各箱中的走势，比较"平的牛顿线"与"MOND 台阶（式 7）"，两者的归一化都自由；
- 检验 C26 的结论"在最干净的样本中没有 MOND 的证据"（牛顿的似然约为 MOND 的 1500 倍），并描述性地探索 C26 第 7 节所说的、能"制造 MOND 假象"的选择（不做球面投影修正、不做赫罗图（HR, Hertzsprung–Russell）切割、更远的距离、更严的视差信噪比）。

## 2. 已知的数字与方法（环节 2 读全文后核实）

- C26 样本：母星表 C25（视差相对误差 ≤ 2.5%，即 parallax_over_error > 40），主分析 ≤ 130 pc；RUWE < 1.25；100 kAU 以内的三体与多重系统去群；赫罗图平行四边形 0.5 < BP−RP < 3.5、高 0.8 mag、斜率 3.3、4 < M_G < 14；ΔRV < 10 km/s；σ(ṽ) < 0.1；ṽ ≤ 2.5（变体 2、1.5）；ipd_frac_multi_peak = 0；质量用 FLAME（约 19% 有），其余用式 12：M⋆ = 10^{0.0725(M_G,⊙ − M_G)}；两星放在逆方差加权的平均视差距离上；做球面投影修正（perspective correction）。
- C26 统计量：各 r_sky/r_M 箱中 ṽ 的中位数，误差 1.4826·MAD/√N；牛顿为平线，MOND 为式 7 的台阶（外场 g_N,e = 1.184 a0，r ≈ r_sky√(3/2)），两者归一化自由；χ² 比较，似然比 exp(Δχ²/2)。
- C26 结果（表 3）：548 倍（N = 1421，ṽ ≤ 2.5）、883 倍（ṽ ≤ 1.5）、1501 倍（N = 1216，ṽ ≤ 1.5 且 ipd = 0）。
- 效应大小：MOND 预期中位数 ṽ 在 r_sky ≳ r_M 处升高约 20%（例如 0.5 → 0.6）；N ≈ 1200–1400 分 6 箱，每箱中位数误差约 0.02–0.03。
- 待核（环节 2）：分箱边界、a0 取值、M_G,⊙、HR 平行四边形的精确顶点、投影修正公式、σ(ṽ) 的误差传播、去群的具体算法（C24 第 2.3 节）、母星表的初始配对条件（角距离、视差一致性、v_sky 上限）。

## 3. 数据与大小（AGENTS.md 第一条）

- 只用 Gaia 档案（gea.esac.esa.int）的服务器端 ADQL：在 parallax > 6.667 mas（150 pc）、parallax_over_error > 40 的母样本上做自连接，配对条件在服务器端算好（角距离对应投影距离 ≤ 100 kAU、视差一致、自行差对应的 v_sky 上限），按赤经分 24 条带用异步查询（async）取数；每颗星只取需要的列（位置、视差、自行、误差与相关系数、G/BP/RP、RUWE、ipd_frac_multi_peak、视向速度、FLAME 质量通过与 astrophysical_parameters 的服务器端连接）。
- 可行性试验（2026-11-14，130 pc、parallax_over_error > 40、RUWE < 1.25、50 kAU、视差差 < 10%）：15° 条带得到 2424 个候选对，用时 42 s；全天约 6 万行，约 10 MB。去群需要 100 kAU 与较宽的母样本，环节 3 先在服务器端计数再写入 README 第 3 节。
- 预算：全部输入估计 10–40 MB，低于 200 MB；单次查询远低于 50 MB 与行数上限。
- **时间约束**：Gaia 数据库 2026-11-25 至 12-02 下线；取数必须在 11-24 之前完成并缓存（缓存在 `%LOCALAPPDATA%`，结果只存小文件）。

## 4. 设计要点与判据方向（预注册写在研究 README 第 2 节）

- **R1（复现样本与中位数曲线）**：同样的切割下，样本数与 C26 的 N（1421、1216）在 ±20% 以内，各箱中位数 ṽ 与 C26 图中的数值在各自误差的 2 倍以内（数值在环节 2 从论文表格或图中核实；拿不到逐箱数值时只比较样本数与总体中位数）。
- **R2（检验 C26 的结论）**：Δχ² = χ²_MOND − χ²_Newton（两者归一化自由，同一组箱）。判定（事先写定）：Δχ² ≥ 2 ln 100 ≈ 9.2 → "牛顿强烈受到偏好（复现 C26 的结论）"；|Δχ²| < 9.2 → "不能区分"；Δχ² ≤ −9.2 → "MOND 受到偏好（与 C26 矛盾）"。另报告似然比与 C26 的 548/883/1501 的比较（描述）。
- **R3（敏感度，只作描述）**：逐项放松 C26 第 7 节列出的选择（不做投影修正、不做 HR 切割、扩展到 150 与 200 pc、改用视差信噪比 > 100 的母星表、不做 ipd 切割、不去群），看 Δχ² 如何变化，并与 C26 的说法对照。
- **R4（可选，描述）**：B24 的距离与切割（250 pc、G < 17 等）下的中位数曲线，作为与 B24 的定性对照；不复现 B24 的完整 MCMC 模型。
- 盲化（blinding）：环节 3 预注册之前不计算任何 ṽ 中位数；可行性试验只计配对数。
