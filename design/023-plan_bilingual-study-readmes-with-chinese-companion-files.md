# 023 · 工作计划：研究 README 中英双语（中文对照文件 README.zh.md）

状态：执行中
创建：2026-11-16
待办：T-029（`TODO.md`）

## 1. 目标

AGENTS.md 第二条要求对外说明文档中英双语，但现有 11 个研究的 `README.md` 只有英文。用户决定（2026-11-16）：研究 `README.md` 也要双语。本计划给每个研究补上中文版，并把规则、模板与测试写定。

## 2. 形式（决定与理由）

- **中文对照文件**：每个研究在 `README.md` 旁加 `README.zh.md`（中文全文），两个文件开头互相链接：英文 `README.md` 在标题下第 3 行加 `> 中文：[README.zh.md](README.zh.md)`，其后空一行，位于原有引用块之前（只在第 1 节之上加一行链接，不改动预注册内容）；中文文件第 3 行链接英文并注明以英文为准。不把中文插进 `README.md`，理由：
  1. `README.md` 第 1–4 节是预注册（pre-registration），其英文原文是判据的唯一权威文本；中文是译文，不改动、不重排英文原文，便于核对预注册是否被事后修改。
  2. 研究 README 长达 300–500 行，含大段表格；两种语言交错会使每次修改、审查与 `git diff` 都加倍复杂。根目录 `README.md` 较短，继续用"## English / ## 中文"的单文件形式。
- **对应关系**：`README.zh.md` 的二级标题与 `README.md` 一一对应（同样的节号与顺序），三级标题（小节与带日期的补充）数目相同，表格数与表格行数相同；数值、单位、天体名称、星表编号、文献、代码、命令、文件名与 JSON 键不翻译（AGENTS.md 双语规则）。术语第一次出现时括注英文。
- **权威性**：`README.zh.md` 开头注明"以英文 `README.md` 为准（预注册与判据的权威文本）"。英文改动时，同一个 PR 同步改中文；测试检查两者的节结构一致（节号、三级标题数、表格数与行数）；措辞与数字的一致靠审查。
- **写作时机**：新研究的 `README.zh.md` 第 1–4 节与英文同时写好（写 `run.py` 之前，预注册）；此后英文的任何改动在同一个 PR 中同步到中文。
- **新研究**：模板 `studies/_template/` 增加 `README.zh.md`；`new-study` 与 `paper-study` 技能写明同时填写中文。

## 3. 环节与审查

1. 规则与基础设施（一个 PR）：本计划、`design/README.md` 索引、AGENTS.md 双语规则一条、模板 `README.zh.md`、两个技能的说明、测试 `tests/test_bilingual_readmes.py`（有 `README.zh.md` 的研究：开头互链、"以英文为准"说明、节号序列、三级标题数、表格数与行数与英文一致、中文标题已填写；另有一个"待翻译"名单，只能是采用规则时已有的 11 个研究，名单中的研究可以暂缺）——双闸审查。
2. 逐个研究翻译（每个研究一个 PR，或把短的合并）：写 `README.zh.md`，从待翻译名单中移除——每个 PR 双闸审查（闸门 1 由不看译文意图的子智能体逐段核对原文与译文：数字、判据、阈值、限定语是否与英文一致，有无增删）。
3. 名单清空后，测试改为要求所有研究都有 `README.zh.md`；计划完成，T-029 移入 DONE。

## 4. 验收标准（acceptance criteria）

- 11 个研究都有 `README.zh.md`，节结构与英文一致，`python -m pytest` 通过；
- 抽查与审查中没有发现与英文不一致的数字、阈值或判据；
- AGENTS.md、模板与技能写明规则，新研究自动带上中文文件。
