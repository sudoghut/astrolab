# 021 · 工作计划：M2 用宿主级随机效应重新检验 CCHP 宿主选择造成的 H0 移动（研究 003）

状态：完成
创建：2026-11-16
待办：T-023（`TODO.md`）

## 1. 目标

研究 003 的 R2 宿主一步（只用 NGC 4258 锚点时，37 个宿主 → CCHP 的 10 个宿主）给出 Δ_h = −0.0730 ± 0.0331 mag（−2.21σ），误差按协方差矩阵（covariance matrix）C 传播。R4 的随机 10 宿主子样本显示 Δ/σ 的离散为 1.33，独立审稿（referee review）指出按此膨胀误差后判定会翻转。本计划在新的预注册（pre-registration）下，用宿主级随机效应（random effect，同一宿主的定标超新星行共享一个偏移，方差 τ²）对 C 作模型化的扩展，用限制最大似然（REML, Restricted Maximum Likelihood）估计 τ，再按原判定表（verdict table）重做宿主（host）一步。数据全部在缓存中，不需取数。

## 2. 范围

- 预注册写在研究 003 `README.md` 第 2 节的附录（2026-11-16，R2-RE）。
- 只改宿主一步的协方差（C → V(τ̂)）；其余判据、宿主标注与判定表不变；原 R2 的记录判定不变。
- 标题判定：R2-RE 的判定行无论是什么，都成为宿主一步的标题判定（取代按 1.33 膨胀误差的那句事后说明）；原 R2 判定作为 2026-11-14 的预注册结果保留；R2-RE 无法判定时，标题仍是 R2 及其原有限定。
- 报告但不决定判定：τ 区间上端的 z、在 V(τ̂) 下重做 R4 的 Δ/σ 离散与 CCHP 百分位（percentile）、37 个逐一剔除宿主的超新星残差的宿主级 χ²。
