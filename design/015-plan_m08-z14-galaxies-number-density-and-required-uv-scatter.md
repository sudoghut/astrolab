## 2. 已知的数字（环节 2 逐条核实引文）

- N26：log φ = −5.36（+0.37/−0.45），−21 < M_UV < −20，z = 14–15；两个天体，约 388 arcmin²（PRIMER-COSMOS、PRIMER-UDS、JOF），体积 462,648 Mpc³；比 JWST 之前的共识模型高 182（+329/−105）倍（基准为 S23 类模型，取文献平均的效率、较小的 σ_UV、Chabrier 初始质量函数（IMF））；所需 σ_UV ≈ 1.5–2 mag（对比聚类约束到 z ≈ 9 的约 0.7 mag）。MoM-z14：M_UV = −20.23 ± 0.06。
- C24：GS-z14-0 z = 14.32（+0.08/−0.20），M_UV = −20.81 ± 0.16；GS-z14-1 z = 13.90，M_UV = −19.0。
- H25 表 2：z ~ 14（13.5–15.0）箱 M = −20.8 处 Φ = 3.7（+8.7/−3.6）× 10⁻⁵；z ≥ 10 的多数点是下限（光谱完备性未知）。
- S23：σ_UV ≈ 0.75 mag（z ~ 9）、≈ 2.0（z ~ 12）、≈ 2.5（z ~ 16）。
- 一处粗算：φ = 2/(V × 1 mag) = 2/462,648 = 4.32 × 10⁻⁶，log φ = −5.364，与 N26 一致。

## 4. 设计要点与判据方向（预注册写在研究 README 第 2 节）

- **R1（数密度的计算）**：由 N = 2、V = 462,648 Mpc³、Δm = 1 mag 复算 log φ，并用泊松置信区间（Gehrels 1986，ApJ 303, 336 的单侧 84.13% 上下限）复算误差。判据：中心值差 < 0.01 dex 且上下误差各差 < 0.05 dex → "复现"。另按 N26 所述的面积与 z = 14–15 在 N26 的宇宙学下复算体积（判据：相对差 < 5%）。
- **R2（与恒定效率晕模型之比，描述+判据）**：晕模型：Eisenstein–Hu 线性功率谱 → σ(M) → Sheth–Tormen 晕质量函数（halo mass function）；用 JWST 之前的 z ≈ 8 UV LF（环节 3 写定具体来源与参数，例如 Bouwens et al. 2021 的 Schechter 参数）做丰度匹配（abundance matching）得到平均关系 M_UV(M_h)，假定该关系不随红移变化（恒定效率），加对数正态 σ_UV = 0.7 mag（N26 所说聚类到 z ≈ 9 的值），外推到 z = 14–15 同一星等箱，得 φ_model。主要结果是比值 R = φ_obs/φ_model 及其区间（φ_obs 的泊松区间）。比较（描述）：R 与 N26 的 182（+329/−105）。判定（项目约定的描述类别）：R 的 68% 区间与 N26 的区间重叠 → "同一量级"；否则写明高低。不称复现 N26 的基准模型（N26 用 S23 类模型，我们的是独立构造）。
- **R3（所需 σ_UV）**：在 R2 的平均关系下，求使 φ_model(σ_UV) = φ_obs 的 σ_UV（及使之等于 φ_obs 泊松区间上下端的值）。判据：所需 σ_UV 的区间与 N26 的"≈ 1.5–2 mag"重叠 → "与 N26 一致"；否则"不同"。与 S23 的 2.0/2.5 mag 只作描述。
- **R4（数据一致性，描述）**：H25 的 z ~ 14 箱（JADES 小面积）与 N26（388 arcmin²）在相近星等处的数密度之比与泊松区间；说明宇宙方差与面积的影响。
- **R5（敏感度，可探索）**：晕质量函数（Sheth–Tormen 对 Press–Schechter）、丰度匹配所用的红移（z ≈ 6、7、8）、完备性假设（φ 按完备性 c 缩放）对 R 与所需 σ_UV 的影响；在 README 第 8 节给出对话探索入口。
- 先验与容差、模型的每个组成在环节 3 写定；环节 2 在 Wiki 中核实所有引文与 N26 的宇宙学参数。
