## 1. 目标

按论文立项流程（`paper-study` 技能，计划 007）把 M8 立为研究：

- 主论文：Naidu et al. 2026（OJAp 9，arXiv:2505.11263，下称 N26）："A Cosmic Miracle"，光谱确认 MoM-z14（z_spec = 14.44 ± 0.02），并由 z = 14–15、−21 < M_UV < −20 的两个天体（MoM-z14 与 JADES-GS-z14-0）推出数密度 log φ = −5.36（+0.37/−0.45）Mpc⁻³ mag⁻¹，称它比"JWST 之前的共识模型"高 182（+329/−105）倍；
- 背景与数据：Carniani et al. 2024（Nature 633, 318，arXiv:2405.18485，下称 C24，JADES-GS-z14-0）；Harikane et al. 2025（ApJ 980, 138，arXiv:2406.18352，下称 H25，z ~ 7–14 的光谱紫外光度函数（UV luminosity function, UV LF）表格）；比较用的模型论文 Shen et al. 2023（MNRAS 525, 3254，arXiv:2305.05679，下称 S23：所需紫外弥散 σ_UV 在 z ~ 12 约 2.0 mag）。
- 在本机检验 N26 论证中可检验的环节：数密度的计算（计数、体积、泊松区间）；一个恒定恒星形成效率（star-formation efficiency, SFE）的晕模型（halo model）在 z ≈ 14.5 的预言，与 N26 自己的基准模型预言直接比较；在固定的中位数关系下需要多大的 σ_UV 才能解释观测（与 N26 的"≈ 1.5–2 mag"和 S23 比较）。

## 2. 已知的数字（环节 2 逐条核实引文）

- N26：log φ = −5.36（+0.37/−0.45），−21 < M_UV < −20，z = 14–15；两个天体（MoM-z14 与 JADES-GS-z14-0），面积 136 + 243 + 9 = 388 arcmin²（PRIMER-COSMOS、PRIMER-UDS、JOF；摘要写"≈ 350 arcmin²"，本研究用正文的 388），体积 462,648 Mpc³（审查者用 Planck18 粗算为 460,463 Mpc³，差 −0.5%，暂定，待 run.py 复算）；误差恰为 Gehrels 1986 的 84.13% 单侧限（N = 2：4.637 与 0.708，即 +0.365/−0.451 dex），论文没有写明方法；比 JWST 之前的共识模型高 182（+329/−105）倍，该模型由 N26 按 S23 的框架构造（文献平均的 SFE、较低的紫外变化性、Chabrier 初始质量函数（IMF）），隐含 φ_model ≈ 4.32 × 10⁻⁶ / 182 ≈ 2.4 × 10⁻⁸ Mpc⁻³ mag⁻¹；所需 σ_UV ≈ 1.5–2 mag（对比聚类推断到 z ≈ 9 的约 0.7 mag，Shuntov+2025）。宇宙学：Planck Collaboration 2018（环节 2 确定具体参数组与 σ8）。MoM-z14：M_UV = −20.23 ± 0.06。
- C24：GS-z14-0 z = 14.32（+0.08/−0.20），M_UV = −20.81 ± 0.16；GS-z14-1 z = 13.90，M_UV = −19.0。
- H25 表 2：z ~ 14（13.5–15.0）箱 M = −20.8 处 Φ = 3.7（+8.7/−3.6）× 10⁻⁵，该箱取自 Robertson+2023，只含 GS-z14-0（与 N26 的计数共用这一天体），误差包含宇宙方差（Somerville+2004，偏置 b = 7）；z ≥ 10 的多数点是下限（光谱完备性未知）。
- S23：σ_UV ≈ 0.75 mag（z ~ 9）、≈ 2.0（z ~ 12）、≈ 2.5（z ~ 16）。
- 一处粗算：φ = 2/(V × 1 mag) = 2/462,648 = 4.32 × 10⁻⁶，log φ = −5.364，与 N26 一致。

## 4. 设计要点与判据方向（预注册写在研究 README 第 2 节）

- **R1（数密度的计算）**：由 N = 2、V = 462,648 Mpc³、Δm = 1 mag 复算 log φ，并用 Gehrels 1986（ApJ 303, 336）的单侧 84.13% 泊松上下限复算误差（只含泊松部分，不含宇宙方差与完备性的不确定性，报告中写明）。判据：中心值差 < 0.01 dex 且上下误差各差 < 0.05 dex → "复现"。另按 388 arcmin² 与 z = 14–15 在 N26 的宇宙学下复算体积（判据：相对差 < 5%；宇宙学参数组、立体角与共动体积积分的约定在环节 3 写定）。写明计算用的是论文报告的两个天体的计数与有效体积，完备性作为明确的假设或局限处理：在 φ_obs = N/(c V Δm) 的定义下，若光谱完备性 c < 1，φ_obs 按 1/c 增大，这给 R5 的完备性方向。
- **R2（恒定 SFE 晕模型的预言，与 N26 基准模型直接比较）**：晕模型：Eisenstein–Hu 线性功率谱 → σ(M) → Sheth–Tormen 晕质量函数（halo mass function）；晕的增长率 Ṁ_h(M_h, z) 用 Fakhouri, Ma & Boylan-Kolchin 2010（MNRAS 406, 2267）的平均（mean）拟合式（中位数拟合式作 R5 敏感度）；SFR = ε(M_h) f_b Ṁ_h；SFR → L_UV 用 Chabrier IMF 的换算系数（环节 3 写定来源，如 Madau & Dickinson 2014 换算到 Chabrier）。ε(M_h) 在 z ≈ 8 用 JWST 之前的光度函数（环节 3 写定，例如 Bouwens et al. 2021 的 Schechter 参数）做去卷积的丰度匹配（abundance matching）：求中位数关系，使其与 σ_cal = 0.7 mag 的对数正态弥散卷积后再现 z ≈ 8 的光度函数；然后冻结 ε(M_h)（作为 M_h 的函数；z ≈ 8 光度函数只约束有限的晕质量范围，z ≈ 14.5 处 M_UV ≈ −20 到 −21 对应更小的晕质量，范围之外的外推规则（如常数或幂律延伸）与该范围在环节 3 写定；ε 吸收了 z ≈ 8 的尘埃消光，即假定尘埃不随红移变化，这一选择写明并在 R5 中与"z ≈ 8 按预注册的 A_UV(M_UV) 去消光、z ≈ 14.5 无消光"比较），在 z = 14–15 用同样的 σ = 0.7 mag 预言同一星等箱的 φ_model。主要比较是模型对模型：φ_model(ours)/φ_model(N26)，其中 φ_model(N26) ≈ 2.4 × 10⁻⁸ 由 N26 的 φ 与 182 倍推出；判据：比值在 1/3 到 3 之间 → "与 N26 的基准同一量级"；否则写明高低。另外对两个模型分别报告观测到 N ≥ 2 的泊松尾概率 P(N ≥ 2 | μ = φ_model V × 1 mag)（描述）。不称复现 N26 的基准模型（独立构造）。模型不确定性：主要判定用环节 3 写定的基准组合（fiducial），并标为"以该组合为条件"；同时预先列出的变体网格（晕质量函数：Sheth–Tormen 与一个模拟校准的形式；晕增长率：Fakhouri+2010 平均与中位数拟合式；校准红移：z ≈ 7 与 8；σ_cal：0.5、0.7、0.9 mag；ε 的外推规则：环节 3 写定的两种）上逐一计算，报告 R2 的判定在全部变体上是否不变（"稳健"）或随变体改变（"依赖校准"），并报告 φ_model 的变体包络。因子 3 的一致只说明在所述构造下两个模型同一量级，不作为对 N26 基准模型的验证。
- **R3（所需 σ_UV）**：在 R2 的中位数关系固定、只改变 z = 14–15 处 σ（以中位数为中心、以星等为单位的对数正态弥散）的前提下，求使 φ_model(σ) = φ_obs 的 σ（主要报告的数字），以及使之等于 φ_obs 泊松区间上下端的值（在此范围内 φ_model(σ) 单调，解唯一；若 σ = 0.7 时 φ_model 已超过某一端，该端记为"σ ≤ 0.7"）。泊松区间跨约 6 倍，所需 σ 的区间会较宽，重叠判定较弱，所以以中心值为主要结果。R3 同样在 R2 的变体网格上计算，报告所需 σ 的变体包络与判定是否稳健；主要判定以基准组合为条件。判据：所需 σ 的区间与 N26 的"≈ 1.5–2 mag"重叠 → "与 N26 一致"；否则"不同"。与 S23 的 2.0/2.5 mag 只作描述。R3 以 R2 的模型构造为前提；若 R2 判为"不同量级"，R3 的判定同时报告这一前提。
- **R4（与 H25 的 z ~ 14 点，背景，不是判据）**：H25 的 z ~ 14、M = −20.8 箱取自 Robertson+2023，只含 GS-z14-0，与 N26 共用这一天体，误差包含宇宙方差，而 N26 的误差只有泊松部分；所以这不是独立的一致性检验。输出：两者的数密度之比、面积之比（约 10 对 388 arcmin²）、各自误差的定义，作为背景说明。
- **R5（敏感度，可探索）**：晕质量函数（Sheth–Tormen 对 Reed et al. 2007 或 Tinker et al. 2008 的模拟校准形式，均为解析式；Sheth–Tormen 在 z > 10 已知有偏差）、晕增长率公式（Fakhouri+2010 对 Dekel+2013）、丰度匹配所用的红移（z ≈ 6、7、8）、校准用的 σ_cal、完备性 c（φ_obs 按 1/c 增大）对 R2 与 R3 的影响；在 README 第 8 节给出对话探索入口。
- 先验与容差、模型的每个组成在环节 3 写定；环节 2 在 Wiki 中核实所有引文与 N26 的宇宙学参数。
