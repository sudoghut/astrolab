## 1. 目标

按论文立项流程（`paper-study` 技能，计划 007）把 M1 立为研究：

- 复现 DESI DR2 只用重子声学振荡（BAO, Baryon Acoustic Oscillations）时 ΛCDM 下的 Ωm 与 h·r_d；
- 复现 DESI DR2 加压缩宇宙微波背景（CMB, Cosmic Microwave Background）先验（compressed prior，把 CMB 信息压缩成少数几个早期宇宙参数的高斯分布）时，演化暗能量模型 w0waCDM 相对 ΛCDM 的偏好（Δχ²_MAP 与等效显著性）；
- 加入超新星（SN, supernova）样本（Pantheon+、Union3、DES-Dovekie），看偏好程度如何随样本变化，并与论文给出的数值对比；
- 为此新增两个核心模块：`astrolab/cosmo.py`（平直宇宙背景演化与 BAO、超新星、CMB 声学尺度可观测量）与 `astrolab/infer.py`（高斯似然（Gaussian likelihood）、对超新星绝对星等的解析边缘化（analytic marginalisation）、最大后验（MAP, maximum a posteriori）寻优、emcee 采样、Δχ² 与显著性换算）。

## 2. 已核实的数字（2026-11-14）

- 只用 BAO，ΛCDM：Ωm = 0.2975 ± 0.0086，h·r_d = 101.54 ± 0.73 Mpc，相关系数 −0.92（式 17）。
- 压缩 CMB 先验（附录 A，式 35–36）：均值 (θ*, ωb, ωbc) = (0.01041, 0.02223, 0.14208)；协方差 10⁻⁹ × [[0.006621, 0.12444, −1.1929], [0.12444, 21.344, −94.001], [−1.1929, −94.001, 1488.4]]。来自 Planck PR4 CamSpec 的早期宇宙压缩（Lemos & Lewis 2023，arXiv:2302.12911），已对积分萨克斯–沃尔夫效应（ISW, Integrated Sachs–Wolfe effect）与 CMB 透镜效应边缘化。
  - **均值的精度**：式 35 的 θ* 只印了 4 位有效数字（0.01041），舍入误差 ±5×10⁻⁶ 约为先验 σ(θ*) = 2.57×10⁻⁶ 的 ±1.9 倍，会明显影响 Δχ²。压缩所用链的公开仓库 `github.com/cmbant/PlanckEarlyLCDM` 的 README（只读，2026-11-14）给出 `means: [[1.04103e-2, 0.02223, 0.1192]]`（参数 `thetastar, ombh2, omch2`）及协方差；把 ωc 换成 ωb + ωc 后，该协方差与式 36 逐项一致，而 0.02223 + 0.1192 + 0.06/93.14 = 0.14207，与式 35 的 0.14208 一致。所以采用 README 所列高斯近似的均值 **θ* = 0.0104103**（6 位有效数字，舍入约 0.02σ；不是原始链的无舍入值），并推断式 35 的 ωbc 均值包含有质量中微子的密度 ων = Σmν/93.14 eV（即 ωm）。**支持解读 A 的间接数值证据**（另一份代码对链参数的注释，不是 DESI 作者的先验配置，不能确认参数定义）：`betoule/cosmologix` 的似然代码（https://github.com/betoule/cosmologix/blob/main/cosmologix/likelihoods.py ，2026-11-14 读取时第 473–516 行，函数文档写明 "Last the DESI paper quote a slightly different prior in omega_bc"）在注释中给出同一条链 `spline_planck_PR4_TTTEEE_lowE_lensing_ISW.likestats` 的 8 位最佳拟合值 ωb = 0.022232079、ωc = 0.11920179（链的均值为 0.022296855、0.11931074），README 的高斯中心正是这一最佳拟合点；ωb + ωc = 0.1414343，加 ων = 0.0006442 得 0.1420785，四舍五入正好是式 35 的 0.14208，不加则为 0.14143。该代码的作者也独立注意到 DESI 引用的 ωbc 先验与链的数值"略有不同"。注意这与论文在式 2 旁的定义 ωbc ≡ (Ωb + Ωc)h² 不一致；两种解读相差 0.00065，约为 σ(ωbc) 的 0.53 倍，会明显改变 Δχ²。**两种解读并列，都作为预注册的比较对象**：解读 A（式 35 的均值约束 ωb + ωc + ων，等价于链中的 ωb + ωc = 0.14143；有上述数值证据）与解读 B（约束 ωb + ωc = 0.14208；符合论文式 2 旁的定义）。每次运行两者都算，结果分别写在 `summary.json` 的 `R2.reading_A_with_nu` 与 `R2.reading_B_without_nu` 下，各自对照判据。R2 的总体判定：两者都通过为"复现"；只有一个通过为"有条件复现（取决于先验的参数定义）"，并写明是哪一个；都不通过为"未复现"。不以哪种解读命中 −8.0 来选择解读，直到有一手来源（作者的似然配置或论文勘误）确认参数定义。可选：经 `fetch.http` 取该链的 `.margestats` 文件（约 10 kB）核对完整精度的均值。

## 4. 设计要点

- **`cosmo`**：平直宇宙（spatially flat universe）的 w0waCDM 背景，暗能量用 CPL（Chevallier–Polarski–Linder）参数化 w(a) = w0 + wa(1 − a)；含光子、三种中微子（两种无质量、一种 0.06 eV 有质量，用费米–狄拉克（Fermi–Dirac）积分求其能量密度）；D_M、D_H、D_V。
  - **Ωm 的定义**：Ωm = (ωb + ωc + ων)/h²，ων = 0.06/93.14。只用 BAO 时 h 与 r_d 简并，采样 Ωm 与 h·r_d；此时 z < 2.5 的 E(z) 中把 0.06 eV 中微子当作物质、忽略辐射（z = 2.33 处 E(z) 的相对误差约 4–5×10⁻⁴，远小于 DESI 单点精度，在第 3 环节的测试中核对）。
  - **r_d**：默认用 Aubourg et al. 2015（arXiv:1411.1074）式 16 的拟合公式（ω_cb 与 ων 分开输入，精度约 0.02%）。式 2 的 0.1432 与 Aubourg 的 ω_cb 都不含中微子，而 CMB 压缩先验的均值含中微子：`cosmo` 中用不同的变量名（`ombc` 为 ωb + ωc，`omm` 为 ωb + ωc + ων），不把先验的值直接代入 r_d 公式，以论文式 2 与声速积分作为交叉核对（式 2 是示意性的幂律，积分配 Eisenstein & Hu 1998 的 z_d 有约 1–2% 的已知归一化偏差，只作数量级核对）。公式在第 3 环节对照原文核实。
  - **θ***：θ* = r_s(z*)/D_M(z*)，z* 用 Hu & Sugiyama 1996 拟合公式，r_s 用数值积分。这是与 θ_MC 类似的拟合公式近似（Planck 2018 中 100θ_MC = 1.04092 与 100θ* = 1.04110 相差 1.7×10⁻⁴，相对，约为先验 σ 的 0.7 倍；我们的近似偏差更大，见下）。原型（2026-11-14，草稿）在 Planck 2018 参数（表 2 后验均值 ωb = 0.02237、ωc = 0.1200、H0 = 67.36）下得到 z* = 1091.9（CAMB 为 1089.92）、100θ* = 1.03974，偏低约 5σ；改用 z* = 1089.92 则为 1.04101。**所以事先就预期需要修正**：采用乘法修正因子 K（θ* = K × θ_HS），在上述参考点把 100θ* 标定为 1.04110。z* 处暗能量几乎不起作用，K 对 w0、wa 几乎不敏感；单点标定只保证参考点本身，所以 R2 称为"带标定近似的复现"，不说成精度已获验证；**预注册 K 为常数**；用第二个参考点（Planck 2018 另一组合的后验均值）的检验报告实际偏差，但只作合理性检查，因为两组合之间的参数差与舍入同量级，无法可靠测出 K 的斜率（要测斜率需要 CAMB）。参考点本身的舍入（约为先验 σ 的一半）作为已知的系统误差，在第 4 环节报告 Δχ² 对 K 改变 ±1 个先验 σ 的敏感度。要更好的参考需要 CAMB；安装 CAMB 要先征得用户同意，本计划不安装。
- **`infer`**：高斯似然；超新星绝对星等的解析边缘化，χ² = ΔᵀC⁻¹Δ − (1ᵀC⁻¹Δ)²/(1ᵀC⁻¹1)；MAP 用有界的多起点寻优，并满足 w0 ∈ [−3, 1]、wa ∈ [−3, 2]、w0 + wa < 0（论文指出 DESI + CMB 压缩先验的组合中 wa 仍受先验下界约束）；后验均值用 emcee 采样；Δχ²_MAP → Nσ（2 个自由度）。采样参数用 (θ*, ωb, ωbc) 还是 (H0, ωb, ωc)，在预注册中决定；这一选择通过雅可比因子（Jacobian）改变后验均值，所以 w0、wa 的判据以 Δχ²_MAP 为主，后验均值只作次要比较。
- **超新星的处理**（第 3 环节写进代码与测试）：
  - Pantheon+：只用 zHD > 0.01 的超新星（去掉大部分造父变星校准星）；先取协方差的子矩阵再求逆；距离用 zHD，(1+z) 因子用 zHEL；不用 SH0ES 的 `MU` 列。
  - Union3：`lcparam_full.txt` 是约 22 个分箱节点（UNITY1.5），配 `mag_covmat.txt`，不是单个超新星。
  - DES-Dovekie：`covtot_inv_000.npz` 已经是逆协方差，可直接做解析边缘化；若要切红移，须用舒尔补（Schur complement）或重新求逆，不能直接切片；对照 Cobaya 的似然与 `config.dataset` 确认 MUERR 是否已含在内，避免重复；读取时 `allow_pickle=False`。
- **复现判据**（预注册写在研究 README 第 2 节，此处只列方向）：
  - R1：只用 BAO 的 Ωm 与 h·r_d（式 17）。
  - R2：DESI + 压缩 CMB 的 Δχ²_MAP = −8.0（2.4σ），容差覆盖 θ* 修正的系统误差（具体容差的算法与数值在研究 README 第 2 节预注册，看到结果之前写定，A、B 两种解读用同一规则）；在两种先验解读（A、B，见第 2 节）下分别判定，总体判定规则见第 2 节；w0、wa 的后验均值为次要比较。
  - R3：不含 CMB 的超新星组合，与表 6 一一对应，可以完全复现：DESI + Pantheon+ −4.9（1.7σ），DESI + Union3 −10.1（2.7σ），以及只用 DESI −4.7（1.7σ）。
  - 压缩 CMB 加超新星的组合（含 Dovekie）只作探索：论文的 +SN 数值用完整 CMB，Dovekie 的 3.2σ 用 Planck + ACT + SPT，都不是同一组数据，不设判据。
- **探索**（对话探索入口）：逐一剔除示踪体（留一法）、换超新星样本、换 w(z) 参数化。
